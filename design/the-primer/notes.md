## How this was made

The round's code is `mock/`, copied in as it ran; it read the design tree's built site through a folder of links (`out/1155/site` in that tree, every entry a link into its `dist/` plus one to this folder), which the archive cannot keep. Run from the tree's root, in this order: `node out/1155/mock/sweep-seeds.ts 1 100` (the seeds), `explore-probe.ts` and `inventory.ts` (what each room shows), `check.ts` (the drift check, with its motion and mutate arms), `landings.ts` (every step done), `pictures.ts`, `shots.ts tops` then `shots.ts` (the stills), `top-row.ts` (the nav), `extra.ts` (D and C at the floor and in every dress, and the trail press), `growth.ts` (the route-tree check on four cases), `contrast.ts`, `fetch-refs.ts`, `ladder-md.ts`, `sheets.ts` (the contact sheets, shot with `--site` set to the main checkout). Each list is shot with `node scripts/design/shoot.ts <list> --site <tree>/out/1155/site --reduced-motion` (or `<tree>/dist`). Every still and sheet came back with no 4xx and no console error, and each sheet's probe read `scrollWidth` equal to the width it was shot at. The main checkout's `design/kit/` was identical to the tree's (`diff -r`), so the sheets wear the faces the site does.
