One more room: one ladder, one line in the list

A subroom needs nothing more: the route tree already seats it under the room it opens from (seatOf in src/layouts/nav.ts), and the guide reads that seat. A room with no ladder fails a unit check over the route tree (untaught below), the way a route with no place fails the chart of the atelier's test today. Run, not described (measure/growth.md): with the Ribbon's ladder taken away, untaught names /ribbon/; with a new subroom of the Explorer in the tree and no ladder, it names that route; given its ladder, the subroom is seated under the Explorer by its place in the tree alone.

export const LADDERS: readonly Ladder[] = [EXPLORER, PROSPECT, RIBBON, PORTFOLIO, WRITING_ROOM, READING_ROOM, PRINT_ROOM, TODAY, GALLERY];

/** The routes the guide leans on rather than teaches, Alex's ruling of 2026-11-05 (Issue #1155 comment 6660218955). */
export const LEANED_ON: readonly string[] = ["/faq/", "/glossary/"];

export function untaught(ladders: readonly Ladder[] = LADDERS, names: Readonly<Record<string, string>> = ROUTE_NAMES, seat: (route: string) => string | null | undefined = seatOf): readonly string[] {
  const taught = new Set([...ladders.map((l) => l.route), ...LEANED_ON]);
  return Object.keys(names).filter((r) => r !== "/" && seat(r) !== undefined && !taught.has(r));
}

The words a step quotes, and how a check finds them

/** A control a step names, found the way a reader's assistive technology names it, and the words the step quotes for it. */
export interface Words {
  readonly css: string;
  /** Exactly the words in braces in the step's sentence. */
  readonly says: string;
  /** How the words are read off the control: its visible text, its accessible name, a select's option, a two-line road's verb and place, or its placeholder. */
  readonly read: "text" | "aria" | "title" | "attr" | "option" | "road" | "placeholder" | "label";
  /** The attribute an "attr" read takes, such as a chart stamp (data-vellum-map-type) or a press state (aria-pressed). */
  readonly attr?: string;
  /** "markup" when the control is in the built page's own HTML, "script" when the room's code builds it after load. */
  readonly from: "markup" | "script";
  /** "starts" where the control's words run on past what the step quotes (a place's name before its rank). */
  readonly match?: "starts" | "contains";
  /** Where the step teaches a control that is not yet to hand: "held" in a held box, or "hidden" until the reader has done the thing the step names (a hunt won, a tablet). */
  readonly state?: "held" | "hidden";
  /** Some words are a room's own on-screen constant, which a build can import rather than retype. */
  readonly constant?: string;
}
