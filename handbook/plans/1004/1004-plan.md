Issue #1004 is item A2 of the codebase scan, Issue #1001. It names 19 neighbour loops in 14 files that destructure each entry of a shared neighbour table (`for (const [dx, dy] of NEIGHBORS_8)`, or `NEIGHBORS_4`) and asks for an indexed loop that binds the entry and reads it (`const n = NEIGHBORS_8[k]!`), byte for byte the same output. This plan changes exactly those 19 loops, and replaces `realm-refine.ts`'s private `NEIGHBORS_4` with the shared one, as the issue asks.

## The design

Every neighbour loop iterates the shared table it iterates today, in the same direction, binds the whole entry to one name, `offset`, and reads the entry by element where it used the destructured names: `offset[0]` for `dx`, `offset[1]` for `dy`, `offset[2]` for the step length (`dist`, `stepDist`, `step`, `length`). The table, its order and the arithmetic are untouched, so every float is the same double computed in the same order; that is what makes the change byte-safe by construction, and the fingerprint below measures it.

`realm-refine.ts`'s private `NEIGHBORS_4` goes, and the file imports the shared one, as the issue asks (same four entries in the same order; the shared one carries a third element nothing here reads).

Rejected, so the builder does not rediscover one:

1. **The issue's own form, an indexed loop that binds the entry and reads it by element** (`const n = NEIGHBORS_8[k]!`). It is exactly as fast as the chosen form (2.77 against 2.72 ms) and changes no byte either; it loses only on size, adding a counter and a non-null mark at every site, where the chosen form changes the loop head's binding and nothing else. This is a style call, not a speed or safety one.
2. **Any loop, indexed or not, that still destructures the entry** (`const [dx, dy] = NEIGHBORS_8[k]!`). It runs at today's speed (10.07 against 10.32 ms): the cost is the destructuring, so an indexed rewrite that keeps it gains nothing. It is a stop condition below.
3. **Flat typed columns exported from `src/core/grid.ts`** (`DX`, `DY`, `STEP`). About 11 ms more off a cold world (469 against 480 ms) and 11 ms more off the voyage, for three new exports that must agree with the tables and a cast at every read.
4. **A callback helper** (`forEachNeighbour(x, y, w, h, fn)`). The early exits (`break` in `watershedDivides` and `coastalParentCells`, `return` in `touchesCorridor` and `bfsPath`) need a second protocol, and a closure call per neighbour is the overhead this issue removes.
5. **Objects in the tables** (`{ dx, dy, step }`). It changes an exported type that `test/core/grid.test.ts`, `test/society/sites.test.ts`, `test/world/realm-refine.test.ts`, `test/world/seat-settlements.test.ts` and `test/world/snap-to-land.test.ts` read.

Not touched, on purpose: the ring loops `for (const [dx, dy] of discOffsets(radius))` in `seatInDisc` (`src/world/seat-settlements.ts`) and the two `offsetsWithin` loops in `src/world/snap-to-land.ts`. They iterate ring offset lists, not a neighbour table, once per settlement rather than once per cell, and Issue #1001 section G records that those two ring generators must not be merged.

**Out of scope by Alex's ruling (M2): six four-neighbour loops of the same shape that the issue does not name.** They stay exactly as they are, and this plan files no issue for them; a later issue can take them if Alex wants one. Measured in situ, rewriting them gained nothing (the "all 25 sites" rows above against "the 19 named sites"); what they would buy is one shared direction list everywhere. They are:
- `growRealmLabels` in `src/world/realm-carry.ts`, over its private `N4`;
- `refineSeaGate` in `src/world/region-sea-gate.ts`, over its private `FLOOD_ORDER` (the same file's `coastalParentCells` loop IS in scope, E19);
- the flood inside `createWaterFlood` in `src/hydrology/lakes.ts`, `largestBlob` in `src/render/blobs.ts`, `shoresTouched` in `src/terrain/detail-guarantees.ts` and `labelLandmasses` in `src/world/landmass.ts`, each over a list written out inline.

### `1004-fingerprint.mts`

```ts
// Issue #1004: hash every output a neighbour loop can reach (world fields, world and region sheets, the voyage, the ribbon road walk, the prospect surroundings), for one tree, so two trees compare in the same environment.
import { createHash } from "node:crypto";

const ROOT = process.argv[2];
if (!ROOT) throw new Error("usage: node 1004-fingerprint.mts <tree root>");
const imp = (p: string) => import(`${ROOT}/src/${p}`);
const { defaultRecipe, generateWorld } = await imp("world/generate.ts");
const { generateRegionWorld, windowAround, regionDetailLevel } = await imp("world/region.ts");
const { createChainCache } = await imp("world/detail-chain.ts");
const { renderMap } = await imp("render/map-renderer.ts");
const { buildPlaceManifest } = await imp("render/place-manifest.ts");
const { buildVoyagePlan } = await imp("render/voyage.ts");
const { buildSurvey } = await imp("render/survey.ts");
const { routeVoyage } = await imp("render/voyage-route.ts");
const { roadMask, roadReachable, roadWalk } = await imp("itinerary/route.ts");
const { plateSurroundings } = await imp("prospect/surroundings.ts");

const h = (v: unknown): string => {
  const hash = createHash("sha256");
  if (typeof v === "string") hash.update(v);
  else if (ArrayBuffer.isView(v)) hash.update(new Uint8Array(v.buffer, v.byteOffset, v.byteLength));
  else hash.update(JSON.stringify(v, (_k, x) => (ArrayBuffer.isView(x) ? Array.from(x as unknown as ArrayLike<number>) : x instanceof Map ? [...x] : x instanceof Set ? [...x] : x)));
  return hash.digest("hex").slice(0, 16);
};

const SEEDS = [42, 7, 1, 3, 11, 99, 123, 2024, 5, 77];
const STYLES = ["antique", "topographic", "ink", "nautical"] as const;
const rows: string[] = [];
let count = 0;
const row = (label: string, v: unknown): void => {
  rows.push(`${label} ${h(v)}`);
  count++;
};

for (const seed of SEEDS) {
  const world = generateWorld(defaultRecipe(seed));
  row(`world ${seed} labels`, world.realms.labels);
  row(`world ${seed} oceanDist`, world.oceanDist);
  row(`world ${seed} flow`, [world.flow.fill, world.flow.dir, world.flow.acc]);
  row(`world ${seed} climate`, [world.climate.temperature.data, world.climate.moisture.data]);
  row(`world ${seed} people`, [world.settlements, world.roads, world.rivers, world.title, world.names]);
  const styles = seed === 42 ? STYLES : (["antique", "nautical"] as const);
  for (const style of styles) row(`svg ${seed} ${style}`, renderMap(world, { style }));
  if (seed === 42 || seed === 7) row(`svg ${seed} legend+arms+beasts`, renderMap(world, { legend: true, arms: true, beasts: true }));

  const manifest = buildPlaceManifest(world, 1500);
  const plan = buildVoyagePlan(manifest.places, manifest.presentYear);
  const survey = buildSurvey(world.elev, world.seaLevel, world.roads);
  const sites = manifest.places.map((p: { idx: number; gx: number; gy: number }) => ({ idx: p.idx, x: p.gx, y: p.gy }));
  row(`voyage ${seed}`, routeVoyage(plan.legs, sites, survey));

  const mask = roadMask(world);
  const walks = world.settlements.map((_s: unknown, i: number) => [roadReachable(world, mask, i), roadWalk(world, mask, 0, i)]);
  row(`ribbon ${seed}`, walks);
  row(`prospect ${seed}`, world.settlements.slice(0, 6).map((_s: unknown, i: number) => plateSurroundings(world, i, manifest.presentYear)));

  if (seed === 42 || seed === 7 || seed === 3) {
    const cache = createChainCache();
    const capital = world.settlements[0];
    const town = world.settlements[Math.min(3, world.settlements.length - 1)];
    for (const [who, s] of [["capital", capital], ["town", town]] as const) {
      for (const size of [0.25, 0.1, 0.04, 0.015]) {
        const window = windowAround(world, s, size);
        const spec = { window, gridW: 320, gridH: 240, title: "probe", detail: true, chainCache: cache };
        const region = generateRegionWorld(world, spec);
        row(`region ${seed} ${who} ${size} fields`, [region.realms.labels, region.oceanDist, region.flow.dir, region.riverCells, region.settlements, region.roads, region.region]);
        const regionRecipe = { window, worldGridW: world.recipe.gridW, detail: regionDetailLevel(spec) };
        row(`region ${seed} ${who} ${size} svg`, renderMap(region, { regionRecipe }));
      }
    }
  }
}
console.log(rows.join("\n"));
console.log(`rows ${count}`);
```

### `1004-cli-compare.mts`

```ts
// Issue #1004: time `chart --seed 42` cold, alternating between two trees, and print each tree's world and render milliseconds as min, median and max.
import { execFileSync } from "node:child_process";
const [base, branch, runsArg, outDir] = process.argv.slice(2);
if (!base || !branch || !runsArg || !outDir) throw new Error("usage: node 1004-cli-compare.mts <base root> <branch root> <runs> <scratch dir>");
const trees = { base, branch } as const;
const world: Record<string, number[]> = { base: [], branch: [] };
const render: Record<string, number[]> = { base: [], branch: [] };
for (let r = 0; r < Number(runsArg); r++) {
  const order = r % 2 ? (["branch", "base"] as const) : (["base", "branch"] as const);
  for (const name of order) {
    const root = trees[name];
    const out = execFileSync("node", [`${root}/src/cli/main.ts`, "chart", "--seed", "42", "--out", `${outDir}/1004-cli-${name}.svg`], { cwd: root, encoding: "utf8" });
    const m = /world (\d+)ms · render (\d+)ms/.exec(out);
    if (!m) throw new Error(`no timing line from ${name}: ${out}`);
    world[name]!.push(Number(m[1]));
    render[name]!.push(Number(m[2]));
  }
}
const q = (a: number[], p: number) => [...a].sort((x, y) => x - y)[Math.floor(p * (a.length - 1))]!;
const fmt = (a: number[]) => `min ${q(a, 0)} median ${q(a, 0.5)} max ${q(a, 1)}`;
for (const name of ["base", "branch"]) console.log(`${name.padEnd(7)} world ${fmt(world[name]!)} | render ${fmt(render[name]!)}`);
console.log(`median world saving ${q(world.base!, 0.5) - q(world.branch!, 0.5)} ms`);
```
