## The design

Each family that is the same logic gets one home under `test-support/`, and every test file that held a copy imports it. Where a `test-support/` module already holds the same kind of helper, the family joins it; otherwise it gets a new module of its own (call C8). A copy is the same logic when its code is the same once names, white space, the function's form (declaration or arrow), `export` and the wording of an assertion's message are set aside; where one copy takes a parameter the others fix, that one is kept and the callers pass the value they fixed (the issue's fix, call C10). Every claim of sameness below is the probe's, not a reading (`out/1317-dry-run/1317-bodies.log`, `1317-bodies-more.log`, `1317-bodies-lint-config.log`). The planner's probes and their logs were in its tree's `out/1317-dry-run/`, which the dispatcher has copied to the main checkout's `out/1317-dry-run/`; every path under `out/1317-dry-run/` in this plan means that folder. Nothing in the build reads them: each figure the build needs is written here.

No assertion changes. Two failure messages change wording (call C11). No test is added, no guard is added or weakened, and the proof is the same counts before and after plus the full suite (Evidence). In all: 65 test files edited, 124 top-level declarations and one inner one deleted, 13 new modules, 4 support modules edited, one spec line rewritten.

Rejected:

- **One `test-support/helpers.ts` holding every family.** It would import the engine, ESLint, the site and the e2e runner into every test that wants one helper, and break the house's one-module-per-concern layout (`test-support/` today).
- **A lint rule refusing a second local definition of a moved name.** The issue asks for none ("no guard is added or weakened"); a rule keyed on names would refuse unrelated helpers that share them (`founded` in `test/render/cartouche-engraving.test.ts`, `press` in four files of other shapes, `near` in `test/repo/memory-pointers.test.ts`).
- **Keeping each helper's name in every case.** Five collide or mislead (call C9).
- **Moving the site `land` by merging the two survey harnesses.** Call C2.
- **Removing the one-line shortcuts and writing the shared call out at their 15 uses.** Ruling 2.
- **Folding the scan's production mirrors** (`ruinedBy`, `tongueOf`, `bilinear` and the rest of the thirteen in `out/jev-copies/notes.md`): a test whose expectation copies the code under test is a question about what the test proves, not about where a helper lives (call C4).
