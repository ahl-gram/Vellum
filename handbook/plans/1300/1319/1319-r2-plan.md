## The design

**The list.** Each entry names both sides by file, name and text hash at a3f00ed1, the original as `a` and the copy as `b`, with a reason and a ruling link that `acceptedFaults` accepts (`https://github.com/ahl-gram/Vellum/issues/<n>#issuecomment-<n>`). **The blind spots, and the way each errs** (replaces the plan's paragraph of that name). The hunt cannot see: a function with fewer than 6 names; a pair under similarity 0.6; the body of a `test(...)` call or any unnamed callback; a getter, a setter or a constructor; an arrow assigned to an existing variable or property (`x = () =>`, `obj.p = () =>`); a function beside one nested inside it; any file but a `.ts` under the lint's roots (stylesheets, pages, `design/`). A function over 6,000 characters is held to exact copies. Each of these hides a copy and none invents one: every one removes a function or a pair from what is compared, and a pair never compared is never reported. The one way the hunt can report a copy that is not one is Jev's answer above 0.7 on a pair that is not the same logic, which the skeptic confirms by reading both; an exact copy can be no such error, since its two texts are the same. The report prints the blind spots as its second line every run. Reading the four new kinds waits for Issue #1332 (ruling 2).
