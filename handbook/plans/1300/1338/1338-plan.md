## What was measured, and what it makes the design

The footgun hook pastes a gate into the session as a hook's added text, and the selftest holds every pasted note to `HOOK_CONTEXT_LIMIT` in `.claude/skills/vellum-footguns/hooks/footgun-gate.selftest.ts`, written out again in "every gate-size probe passes at the 8,000-character limit" in `test/repo/footgun-gate.test.ts`. That 8,000 is not a house choice: Issue #708's ruling D took the stricter of two cuts read from Claude Code 2.1.287, a switch to a 2,000-character preview past 10,000 and an 8,000-character cut whose reach on a project hook was unverified.

Measured 2026-11-11 on Claude Code 2.1.322 with Haiku, a throwaway project whose only settings held one PreToolUse hook that added exactly N characters ending in the line `MARK-N-END`, and no user settings or user hooks loaded. Each cell is read three ways: the debug log's "provided additionalContext (N chars)" and whether a "Persisted tool result" line follows, the session transcript's recorded attachment (its length and whether the marker is in it), and the session's own report.

| path | 7,900 | 8,100 | 9,499 | 9,900 | 10,100 | 10,499 |
|---|---|---|---|---|---|---|
| non-interactive session (`claude -p`) | | | whole | | | 2,000-character preview |
| interactive session (a real terminal, driven by `expect`) | whole | whole | | whole | preview, marker gone | |
| agent dispatched from a non-interactive session | whole | whole | | whole | preview, marker gone | |
| agent dispatched from an interactive session | whole | whole | | whole | preview, marker gone | |
| the cloud routine | UNVERIFIABLE: no way in from here | | | | | |

"Whole" means the transcript's attachment held all N characters with the marker and the session saw the marker; "preview" means the attachment was 2,299 characters (a 2,000-character preview in its `<persisted-output>` wrapper, labels L001 to L020) with the rest saved to a file. The program also carries an 8,000-character and 200-line cut on a hook's added text (read from the installed program, not run); on none of the four measured paths did a note reach it.

So the binding limit on every measured path is Claude Code's switch to a preview, which lies between 9,900 and 10,100 characters; the 8,000 cut binds nowhere measured.

**The design:** `HOOK_CONTEXT_LIMIT` becomes 9,000, 1,000 under that switch and 900 under the largest note measured whole, with one dated line at the constant naming the measurement. The test that writes the limit out follows it. No gate's text changes, so no pasted note changes size today; every gate gains about 1,000 characters of room (Gate 1's worst probe 7,966 of 9,000, Gate 2's 7,927 of 9,000). The hook README's sentence that names the number points at the constant instead, and the errata row recording that Gate 2's note sat close to 8,000 is deleted as fixed.
