## The design (ruled: D1 option 1)

The hand stops being told which room it is in. `bootHand` takes the route from `env.location.pathname`, the same `location` it already reads the step key from, and `bootHandOnce` takes no argument. The nine room literals are deleted, so a copied-wrong room name cannot exist, and the type checker refuses an argument put back (`TS2554: Expected 0 arguments, but got 1`, measured: `out/1389-dry-run/1389-arity.ts` in the planner's tree, `tsc --noEmit --strict --target es2022 --module nodenext out/1389-dry-run/1389-arity.ts`, log `out/1389-dry-run/1389-arity.log`, at e788ca7d). `HandRoom` is deleted, so no caller, a test included, can boot the hand with a room the address does not name.

Why the pathname is the route: every Try it address is `stepAddress(step.id, step.at)` (`src/site/shared/primer/hand-steps.ts`), and each step's `route` is `routeOf(step.at)`, the path before `?` or `#`, so the address a reader arrives at carries exactly the route `handStepFor` compares. `astro.config.ts` sets `trailingSlash: "always"` and base `/`; no room writes its path (every `history.replaceState` under `src/site/` writes a `#` fragment alone, `git grep -n "pushState\|replaceState" -- src/site`); each room's bundle is loaded by its own `src/pages/<room>/index.astro` and no other page (`git grep -n "app.bundle.js" -- src/pages`).

What changes for a reader, measured on the live host (2026-11-25, `curl -sI`): `/print-room?step=print-room-keep` answers 301 to `/print-room/?step=print-room-keep`, key kept, so the hand still boots; `/print-room/index.html` answers 200, so a step key on that form now opens no hand where the literal would have. No page, script or ladder step writes that form (`git grep -n "index\.html" -- src/site src/pages src/layouts src/components e2e/suites e2e/support` prints nothing; no step's `at` holds `index.html`, 0 of 81).

### Alternatives rejected

- **A house lint rule refusing a `bootHandOnce` route that is not its file's folder, the nine literals kept** (D1 option 2): not ruled; it keeps the literals the ruling deletes and adds a rule, its plants and a source witness.
- **The issue's unit test reading each room's script** (D1 option 3, not ruled): `handbook/specs/check-placement.md` rules "A unit test does not open a source file and search its text", and `test-support/source-read-guard.ts` reds an unlisted read of any `src/**/*.ts` (`SOURCE` and `verdictLines` there); no kind in `SOURCE_READS` fits (`data` is a file that is the thing under test, `witness` backs a lint rule, and `kept` admits no new entry). `test/site/app-bundles.test.ts` is also 390 lines, so a test there would force a split.
- **Normalizing `/index.html` in `bootHand`**: code for an address nothing on the site produces (C3).
- **Keeping `HandRoom` and having `bootHandOnce` pass `{ route: location.pathname }`**: keeps a state the page cannot reach (a route other than the address's) and the tests that exercise it, as PK14's `elsewhere.run("/prospect/")` at an `/explorer/` address does today (C4).
- **A browser check opening a `?step=` address in each room**: a unit test holds the claim alone, and under this design no room carries an input of its own (check-placement, the bullet opening "A claim goes to a unit test").
- **A text search of each built bundle for its route**: a text search, and a bundle names other rooms' routes in its links.

**T1. PK31** in `test/site/primer-hand-note.test.ts`, written as:

```ts
test("PK31 bootHand takes its room from the page's own address: in each room that takes the hand, one of its steps opens the note at that room's address and none at the next room's (Issue #1389)", async () => {
  for (const [i, room] of HAND_ROOMS.entries()) {
    const step = STEPS.find((s) => s.route === room);
    assert.ok(step !== undefined, `no step is addressed to ${room}, so this room reads nothing here`);
    const next = HAND_ROOMS[(i + 1) % HAND_ROOMS.length]!;
    const own = booted(`${room}?step=${step.id}`);
    await own.run();
    assert.equal(own.document.querySelector(".primer-slip") !== null, true, `${step.id} opens no note at ${room}, its own room`);
    const elsewhere = booted(`${next}?step=${step.id}`);
    await elsewhere.run();
    assert.equal(elsewhere.document.querySelector(".primer-slip") === null, true, `${step.id}, a step of ${room}, opens a note at ${next}`);
  }
});
```
