## The design

1. **Two tracked links**, `.agents/skills/vellum-footguns` and `.agents/skills/comment-sweep`, each a symlink (git mode `120000`) whose text is `../../.claude/skills/<name>`. The skill folders stay where they are, so no citation moves and there is no second copy **(Q1, ruled)**.
2. **One new test file, `test/repo/skill-links.test.ts`**, holding three claims about the real tree and, beside each, a test of its checker over fixtures in a temporary folder:
   - every tracked skill (a `SKILL.md` directly in a folder under `.claude/skills/`) has a tracked entry `.agents/skills/<name>` committed as a link, and nothing else is tracked under `.agents/skills/` (G1, read from the index, which is what a clone checks out; fixtures G2);
   - each link on disk is a symlink whose text is exactly `../../.claude/skills/<name>` and which resolves (G3, read from the working tree, which is what a prover's mutation changes; fixtures G4);
   - each `SKILL.md` read through its link has front matter whose `name` is the folder's name and whose `description` is not empty (G5; fixtures G6, and the reader's own arms G7).
3. **`frontMatterOf` moves from `test/repo/front-matter.test.ts` into a new `test-support/front-matter.ts`**, unchanged, beside a new `topLevelScalar` that reads a one-line top-level key's plain, double-quoted or single-quoted value. Its blind spots are named in one comment line at the function.
4. **`.agents/skills/vellum-footguns` joins the code list of `test/repo/docs-only.test.ts`** (G8), so a pull request that changes only a link still runs every lane; `scripts/docs-only.ts` is not changed.
5. **One paragraph in `handbook/specs/conventions.md`**, Where a rule lives: a skill is written once in its folder and Codex reads it through its link.
6. **Evidence outside the unit suite**: the Codex agent's two real-tree mutations (R1, R2, in `implementer-proof.md`), a fresh partial clone of the pushed branch with the test run inside it (`fresh-clone-check.md`), and the skills check in fresh sessions (`codex-skills-check.md`, **Q2, ruled**).

### Alternatives rejected, so the build does not rediscover one

- **A unit test that runs `git clone`.** A clone reads the last commit, so it stays green under every uncommitted mutation a prover makes, and it would download or copy a 431.6 MB tree (`git ls-tree -r -l HEAD`). CI's `check & test` jobs already run the test in a fresh `actions/checkout@v4` clone on every pull request and every push to main (`.github/workflows/ci.yml`); the one-time `fresh-clone-check.md` covers the branch before review.
- **A YAML library for the two keys.** None is a declared dependency (`yaml` and `smol-toml` are in `node_modules` only as another package's dependencies, and importing one undeclared is the wrong way to take a dependency); `test/repo/front-matter.test.ts` already holds every skill's front matter to valid YAML through Prettier's parser, so a one-line-key reader over valid YAML has the named blind spots and no other.
- **Copying `frontMatterOf` into the new test.** `vellum/no-word-for-word-copy` (`scripts/lint/word-for-word.ts`) refuses a second copy, and Gate 1 item 8 puts a shared helper in `test-support/`.
- **Only real-tree tests.** The guard prover changes source only through `node scripts/agent-sandbox.ts mutate`, which refuses any path that is not a regular tracked file (`trackedFile` and `containedFile` in `scripts/agent-sandbox.ts`), so it cannot make a real link dangle or turn into a folder. The fixture tests hold each such shape where the prover can break the checker by line; the precedent is the second test in `test/repo/front-matter.test.ts`. The two real-tree shapes it cannot reach are the Codex agent's R1 and R2.
- **Checking that the link resolves to the same real path as the skill folder** (a `realpathSync` comparison). With the link's text pinned exactly and G1 refusing anything but link entries under `.agents/skills/`, resolving at all is the whole remaining case; the comparison would be a branch no fixture could reach short of making `.agents` itself a link.
- **Adding `.agents/skills` to the roots of `test/repo/prose-paths.test.ts` or `test/repo/memory-pointers.test.ts`.** The links lead to files those tests already read under `.claude/skills/`, so it would read each one twice, which the issue asks to show does not happen.
- **Editing `CLAUDE.md`'s "What is tracked" line.** Sub 7 owns the main-session instructions and the byte budget Codex loads `AGENTS.md` under (matrix X-22); the convention lives in its spec.

**`test-support/front-matter.ts`** (commit 1, final):

```ts
export function frontMatterOf(text: string): string | null {
  return /^---\r?\n([\s\S]*?)\r?\n---\r?\n/.exec(text)?.[1] ?? null;
}

// Reads a key written on one line at the top level of front matter that test/repo/front-matter.test.ts already holds to valid YAML: a block scalar (`|` or `>`) reads as its indicator and a value carried onto a second line as its first line, so both err toward a pass, and a double-quoted escape JSON lacks throws, which errs toward a red.
export function topLevelScalar(frontMatter: string, key: string): string | null {
  const raw = new RegExp(`^${key}:[ \\t]*(.*?)[ \\t]*\\r?$`, "m").exec(frontMatter)?.[1];
  if (raw === undefined) return null;
  if (raw.startsWith('"')) {
    const value: unknown = JSON.parse(raw);
    return typeof value === "string" ? value : null;
  }
  return raw.startsWith("'") ? raw.slice(1, -1).replaceAll("''", "'") : raw;
}
```

`frontMatterOf` is the function `test/repo/front-matter.test.ts` holds today, moved byte for byte with `export` added. The comment is the scanner's named blind spots and their direction (`CLAUDE.md`, Process, "a scanner proves which way it errs"), one line.

**`test/repo/skill-links.test.ts`** (commit 1, final):

```ts
import { test } from "node:test";
import assert from "node:assert/strict";
import { spawnSync } from "node:child_process";
import {
  existsSync,
  lstatSync,
  mkdirSync,
  mkdtempSync,
  readFileSync,
  readlinkSync,
  rmSync,
  symlinkSync,
  writeFileSync,
} from "node:fs";
import { tmpdir } from "node:os";
import { join, resolve } from "node:path";
import { frontMatterOf, topLevelScalar } from "../../test-support/front-matter.ts";

const REPO = resolve(import.meta.dirname, "..", "..");
const AUTHORED = ".claude/skills";
const EXPOSED = ".agents/skills";
const LINK_MODE = "120000";
// 2026-11-18: this git ls-files answers in under 5 ms on a Mac; thirty seconds is a cap on a hang, not a budget.
const GIT_TIMEOUT_MS = 30_000;

type IndexEntry = { readonly mode: string; readonly path: string };

const linkText = (name: string): string => `../../${AUTHORED}/${name}`;

function indexEntries(root: string): readonly IndexEntry[] {
  const listing = spawnSync("git", ["ls-files", "-s", "-z", "--", AUTHORED, EXPOSED], {
    cwd: root,
    encoding: "utf8",
    timeout: GIT_TIMEOUT_MS,
  });
  assert.equal(listing.status, 0, `git ls-files failed: ${listing.error?.message ?? listing.stderr}`);
  return listing.stdout
    .split("\0")
    .filter(Boolean)
    .map((line) => ({ mode: line.slice(0, line.indexOf(" ")), path: line.slice(line.indexOf("\t") + 1) }));
}

function repoIndex(): { readonly skills: readonly string[]; readonly links: readonly IndexEntry[] } {
  const entries = indexEntries(REPO);
  const skills = entries
    .map((e) => e.path.split("/"))
    .filter((parts) => parts.length === 4 && `${parts[0]}/${parts[1]}` === AUTHORED && parts[3] === "SKILL.md")
    .map((parts) => parts[2] ?? "");
  assert.ok(skills.length > 0, `git listed no SKILL.md under ${AUTHORED}/, so this test would read nothing`);
  return { skills, links: entries.filter((e) => e.path.startsWith(`${EXPOSED}/`)) };
}

function rosterProblems(skills: readonly string[], links: readonly IndexEntry[]): readonly string[] {
  const wanted = skills.map((name) => `${EXPOSED}/${name}`);
  return [
    ...wanted.filter((path) => !links.some((l) => l.path === path)).map((path) => `${path} is not tracked`),
    ...links
      .filter((l) => !wanted.includes(l.path))
      .map((l) => `${l.path} is tracked but names no skill under ${AUTHORED}/`),
    ...links
      .filter((l) => wanted.includes(l.path) && l.mode !== LINK_MODE)
      .map((l) => `${l.path} is committed as mode ${l.mode}, not as a link (${LINK_MODE})`),
  ];
}

function exposureProblems(root: string, skills: readonly string[]): readonly string[] {
  return skills.flatMap((name) => {
    const link = join(root, EXPOSED, name);
    const stat = lstatSync(link, { throwIfNoEntry: false });
    if (stat === undefined) return [`${EXPOSED}/${name} is missing`];
    if (!stat.isSymbolicLink()) return [`${EXPOSED}/${name} is not a link`];
    const text = readlinkSync(link);
    if (text !== linkText(name)) return [`${EXPOSED}/${name} points at ${text}, not ${linkText(name)}`];
    if (!existsSync(link)) return [`${EXPOSED}/${name} does not resolve, since ${AUTHORED}/${name} is missing`];
    return [];
  });
}

function frontMatterProblems(root: string, skills: readonly string[]): readonly string[] {
  return skills.flatMap((name) => {
    const file = `${EXPOSED}/${name}/SKILL.md`;
    try {
      const frontMatter = frontMatterOf(readFileSync(join(root, file), "utf8"));
      if (frontMatter === null) return [`${file} has no front matter`];
      const problems: string[] = [];
      if (topLevelScalar(frontMatter, "name") !== name) problems.push(`${file} does not give its name as ${name}`);
      if ((topLevelScalar(frontMatter, "description") ?? "").trim() === "") problems.push(`${file} has no description`);
      return problems;
    } catch (error) {
      return [`${file} cannot be read through its link: ${error instanceof Error ? error.message : String(error)}`];
    }
  });
}

function inTree(skills: readonly string[], run: (root: string) => void): void {
  const root = mkdtempSync(join(tmpdir(), "skill-links-"));
  try {
    mkdirSync(join(root, EXPOSED), { recursive: true });
    for (const name of skills) {
      mkdirSync(join(root, AUTHORED, name), { recursive: true });
      writeFileSync(
        join(root, AUTHORED, name, "SKILL.md"),
        `---\nname: ${name}\ndescription: The ${name} skill.\n---\n`,
      );
    }
    run(root);
  } finally {
    rmSync(root, { recursive: true, force: true });
  }
}

const link = (root: string, name: string, text: string = linkText(name)): void =>
  symlinkSync(text, join(root, EXPOSED, name));

test("every skill under .claude/skills/ has one tracked link at .agents/skills/<name>, committed as a link, and nothing else is tracked there", () => {
  const { skills, links } = repoIndex();
  assert.deepEqual(
    rosterProblems(skills, links),
    [],
    `each skill folder under ${AUTHORED}/ owes Codex a link: ln -s ../../${AUTHORED}/<name> ${EXPOSED}/<name>, then git add it (handbook/specs/conventions.md, Where a rule lives)`,
  );
});

test("the roster check refuses a skill with no link, a tracked path that names no skill, and a link committed as a file or a folder", () => {
  const entry = (name: string, mode: string = LINK_MODE): IndexEntry => ({ mode, path: `${EXPOSED}/${name}` });
  assert.deepEqual(rosterProblems(["a", "b"], [entry("a"), entry("b")]), []);
  assert.deepEqual(rosterProblems(["a", "b"], [entry("a")]), [".agents/skills/b is not tracked"]);
  assert.deepEqual(rosterProblems(["a"], [entry("a"), entry("z")]), [
    ".agents/skills/z is tracked but names no skill under .claude/skills/",
  ]);
  assert.deepEqual(rosterProblems(["a"], [entry("a", "100644")]), [
    ".agents/skills/a is committed as mode 100644, not as a link (120000)",

  assert.deepEqual(rosterProblems(["a"], [entry("a/SKILL.md", "100644")]), [
    ".agents/skills/a is not tracked",
    ".agents/skills/a/SKILL.md is tracked but names no skill under .claude/skills/",

test("each link is the relative path ../../.claude/skills/<name> and resolves to that skill's folder", () => {

test("the link check refuses a missing link, a copied folder, an absolute link, another skill's path and a link whose skill folder is gone", () => {
  inTree(["a"], (root) => {
    link(root, "a");
    assert.deepEqual(exposureProblems(root, ["a"]), []);
  });
  inTree(["a"], (root) => {
    assert.deepEqual(exposureProblems(root, ["a"]), [".agents/skills/a is missing"]);
```
