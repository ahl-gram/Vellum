## The design

In `compareLines` (`scripts/still-judge/report.ts`), each other picture's line tests today's `notAnswered` before its own: when today's picture was not answered, every other line reads `<path>: not compared: today's picture was <today's reason>`; when today was answered and the other was not, it reads `<path>: not compared: <the other's reason>`; when both were answered, the comparison lines as now. The line texts themselves do not change, only which branch wins. The first line's counts (`refused unsent`, `skipped`) still carry every picture's state, so the other's own reason, when today also failed, is counted there and no longer named on its line. That trade is the issue's own: its second case (today skipped, the other refused) expects `today's picture was skipped`.

The issue's claim "No other file pins the order" is STALE: `test/repo/still-judge-main.test.ts` pins it three times (lines 33, 37 and 43), each in a keyless or dry-run subprocess where today's picture is itself unanswered, so the fix reds all three. And `.claude/agents/vellum-plate-reader.md` line 76 matches the keyless and no-network lines by the text `not compared: skipped`, which the fix turns into `not compared: today's picture was skipped`. Both move with the code in this pull request.

What the recipe in `.claude/agents/vellum-plate-reader.md` quotes from `compare`, after PR #1352: the last line of `lines.txt` (`COMPARISON_RULE`, unchanged), each `stderr.log` line (the usage-log failure and the usage, both unchanged), and the exit status (`compare` in `scripts/still-judge/main.ts` line 54, untouched). The one text it matches is line 76's `not compared: skipped`, rewritten below.

Rejected:
- **Name both reasons on the line** (`today's picture was refused unsent: ...; this one was skipped: ...`): a new line shape for a case the first line's counts already cover, and redundant in the commonest case, a run with no key or no network, where both reasons are the same.
- **Today first only when the reasons differ** (recon's option b): a branch whose only effect is to choose between two identical reasons, so it carries no information and adds a case to test.
- **Today first only when today was refused unsent** (recon's option c): fails the issue's own second case, where today was skipped and the other refused. Mutation 2 below is this alternative, and the new test refuses it.
- **A guard that the plate reader's recipe never sends a picture outside the limits** (recon's third note, its claim UNVERIFIABLE): outside this issue, and the recipe already holds it in prose, since its step 6 shoots every still at 1500 by 1158 and its step 5 names and leaves out any sheet not drawn at that size.
