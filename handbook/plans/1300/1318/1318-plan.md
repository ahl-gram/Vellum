## The design

**Every pair is read for how its test uses the copy, then settled by the issue's own three steps.** A copy that only builds a fixture or reads a result (class A), or that is kept equal to its production twin on purpose (class B), stays and gets one line saying which. A copy that is the oracle an assertion takes its expected value from (class C) is deleted, and the assertion it served is rewritten to hand-worked values on a chosen input, or to a property that needs no copy. Wherever a copy stays, the rule it shares with production is shown to be pinned somewhere by values that come from neither copy, so a slip written into both still reds a test.

### T1, `test/render/iso.test.ts`, new: "isolines: a closed ring survives while its longer side spans 0.6 cell or more, and is culled below it"

```ts
test("isolines: a closed ring survives while its longer side spans 0.6 cell or more, and is culled below it", () => {
  const closedAt = (field: Field, levels: number, v: number): boolean =>
    isolines(field, levels).some((s) => Math.abs(s.value - v) < 1e-9 && s.contours.some((c) => c.closed));
  const spike = createField(5, 5, (x, y) => (x === 2 && y === 2 ? 1 : 0));
  assert.equal(closedAt(spike, 19, 0.65), true, "a lone spike's 0.65 ring spans 2 x 0.35 = 0.7 cell, and survives");
  assert.equal(closedAt(spike, 19, 0.75), false, "its 0.75 ring spans 2 x 0.25 = 0.5 cell, and is culled");
  const bar = createField(7, 5, (x, y) => (y === 2 && (x === 2 || x === 3) ? 1 : 0));
  assert.equal(closedAt(bar, 19, 0.75), true, "beside a second high cell the 0.75 ring is 1.5 cells long and 0.5 tall, and the longer side keeps it");
  assert.equal(closedAt(bar, 19, 0.95), true, "its 0.95 ring, 1.1 cells long and 0.1 tall, survives too");
});
```

Hand-worked: a ring at level v crosses each edge out of a unit spike (1 - v) cells from the peak, so its box is 2(1 - v) a side; beside a second high cell it is one cell longer. The 0.7 level (0.6 cell by hand, 0.5999 in floating point) is deliberately not asserted. The bar is the only fixture that tells the larger side from the smaller.

