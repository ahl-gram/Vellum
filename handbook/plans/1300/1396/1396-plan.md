5. **A helper shares its parent's `session_id`** (X-06).
6. **`timeout` (seconds, default 600) and `additionalContextLimit` (approximate tokens, default 2500; `0` passes the note whole) are fields of each handler in `hooks.json`** (hooks page), so both live in the frozen definition. A hook that times out lets the call run (X-12).

## The design

**One frozen registration, one launcher, one adapter, and the engine unchanged.**

1. **`.codex/hooks.json`** registers one `PreToolUse` handler for `Bash|apply_patch` **(O4, ruled)**. Its command climbs from the folder Codex runs it in (the session's starting folder) to that folder's repository with `git rev-parse --show-toplevel`, and runs `scripts/agent-infra/hooks/codex-launcher.ts` there if it exists, exiting 0 otherwise. It never reads `CLAUDE_PROJECT_DIR`. `timeout` is 10 **(O7, ruled)** and `additionalContextLimit` is 0 **(D4 as O5, ruled)**. The file holds no logic and is pinned byte for byte by a test, because any change makes Codex skip the hook until Alex trusts it again.
2. **`scripts/agent-infra/hooks/codex-launcher.ts`** is the frozen path the command names, two statements, no policy, mirroring the Claude launcher.
3. **`scripts/agent-infra/hooks/codex-adapter.ts`** turns a Codex payload into the engine's `HookRequest`: a `Bash` call becomes one shell operation **(O1, ruled)**; any other tool, `apply_patch` included until Sub 4, gets no decision. The caller is `main` without `agent_id` and `subagent` with it; directory persistence is the constant `false` **(O2, ruled)**, so the bare-`cd` refusal never fires under Codex; the session directory is the hook process's working folder; the operation directory is the payload's `cwd`; the policy root is the checkout the adapter sits in **(O3, ruled)**, which is the checkout the command found from the session's starting folder.
4. **`scripts/agent-infra/hooks/hook-io.ts`** is new and shared: `HOOK_CHECKOUT` (moved from the Claude adapter's `POLICY_ROOT`), `Decision`, `decisionFor` (today's tail of `decide`) and `runHook` (today's `runClaudeHook` body). The Claude adapter moves onto it with no change in behavior, so the Codex adapter writes neither the output shape nor the stdin loop a second time (`vellum/no-word-for-word-copy`).
5. **The gate state appends (O9, ruled)**: `rememberGate` appends `<gate>\n` to `<tmpdir>/vellum-footguns-<session_id>.txt` and `shownGates` reads its lines. A read-modify-write of the whole file loses gates when two hooks write at once (measured, 20 of 20); an append cannot overwrite another's line. The suffix changes from `.json` so a session's old JSON file is never read half right; it is ignored, which repeats a gate at most once. This reaches Claude sessions too: a gate is no longer lost in a race, and nothing else changes.

**D7, its Codex wording (O3, ruled):** the rules come from the checkout the Codex session was started in. A helper working in a lane's folder reads the main copy's rules, as a Claude subagent does; a session started inside a lane's worktree reads that worktree's rules, as a Claude session started there does. A worktree cut before the launcher existed runs nothing and is not checked, as a Claude session in such a tree is not.

### Alternatives rejected, so the build does not rediscover one

- **Locating the launcher from the payload's `cwd`.** That is each call's folder (X-34), so a helper in a lane would get the lane's rules: the D7 break the issue forbids.
- **An absolute path to the main checkout in the command.** Sub 1's fixture used one; it would run main's code for a session started in a lane, unlike Claude, and is the "hardcode the main checkout" mutation.
- **Walking up past a worktree's root to find a launcher.** An older lane would silently run the main checkout's hook; the command stops at the session's own repository root and exits 0.
- **Logic in the command itself** (a shell loop, `node -e`). Every change to it costs a trust; the command only finds a file.
- **An atomic temp-file rename for the state** (plan section 8.5's first remedy). It stops a torn read but not a lost update: each writer renames its own stale copy over the other's, and it lost gates in 20 of 20 measured runs.
- **A lock folder around the state** (plan section 8.5's second remedy). It lost none in 20 runs, but it waits, and a hook killed while holding the lock leaves it behind, so every later reminder waits out the bound and is never recorded; appending needs neither the wait nor a way to clear a stale lock. Alex ruled append (O9).
- **A Codex corpus as its own `node:test` file.** The body-file rows need the selftest's scratch files; the pass runs inside the selftest instead, where they exist.
- **A `.codex/config.toml`.** Nothing ruled needs one (Recon, rejected).
- **Editing `CLAUDE.md`, `AGENTS.md` or `SKILL.md`.** Their hook lines stay true; Sub 7 owns the main-session instructions and their byte budget (Calls made).

import { readFileSync } from "node:fs";
import { resolve } from "node:path";
import { deliver, evaluate } from "./engine.ts";
import type { HookRequest } from "./request.ts";

export const HOOK_CHECKOUT = resolve(import.meta.dirname, "..", "..", "..");

type Output = {
  hookEventName: "PreToolUse";
  permissionDecision?: "deny";
  permissionDecisionReason?: string;
  additionalContext?: string;
};
export type Decision = { hookSpecificOutput: Output } | null;

export const decisionFor = async (request: HookRequest | null): Promise<Decision> => {
  if (request === null) return null;
  const delivery = deliver(request, await evaluate(request));
  if (delivery === null) return null;
  return delivery.kind === "deny"
    ? {
        hookSpecificOutput: {
          hookEventName: "PreToolUse",
          permissionDecision: "deny",
          permissionDecisionReason: delivery.reason,
        },
      }
    : { hookSpecificOutput: { hookEventName: "PreToolUse", additionalContext: delivery.text } };
};

export const runHook = async <P>(decide: (payload: P) => Promise<Decision>): Promise<void> => {
  try {
    const result = await decide(JSON.parse(readFileSync(0, "utf8")) as P);
    if (result) process.stdout.write(JSON.stringify(result));
  } catch {
    /* a malformed payload or a missing SKILL.md fails open */
  }
  process.exit(0);
};
```

**`test-support/footgun-gate/codex-rows.ts`** (commit 1, final):

import { rmSync } from "node:fs";
import type { Payload } from "../../scripts/agent-infra/hooks/claude-adapter.ts";
import { decideCodex, type CodexPayload } from "../../scripts/agent-infra/hooks/codex-adapter.ts";
import { statePath } from "../../scripts/agent-infra/hooks/gate-state.ts";
import { CD_ROWS } from "./bare-cd.fixtures.ts";
import { bash, judged, NEEDLES, placed, ROOT, type Fixture, type Kind } from "./kit.ts";

type CodexRow = readonly [name: string, payload: Payload, want: Kind, needle: string, absent?: string];

export const asCodex = (payload: Payload, session: string): CodexPayload => ({
  session_id: session,
  cwd: payload.cwd ?? ROOT,
  tool_name: payload.tool_name,
  tool_input: { command: payload.tool_input?.command ?? "" },
  ...(payload.agent_id === undefined ? {} : { agent_id: payload.agent_id, agent_type: "vellum-implementer" }),
});

const shellRows = (table: readonly Fixture[]): CodexRow[] =>
  table.flatMap(([name, subject, want, needle, absent]): CodexRow[] =>
    typeof subject === "function" || subject.tool_name !== "Bash" ? [] : [[name, subject, want, needle, absent]],
  );

const cdRows = (): CodexRow[] =>
  CD_ROWS.map(([name, command, cwd, , who]): CodexRow => {
    const refused = who === "stash" || who === "escape";
    return [
      `a cd: ${name}`,
      {
        ...bash(placed(command), cwd === null ? undefined : placed(cwd)),
        ...(who === "subagent" ? { agent_id: "a781" } : {}),
      },
      refused ? "deny" : null,
      refused ? (NEEDLES[who] ?? "") : "",
    ];
  });

export const codexChecks = async (
  report: (ok: boolean, line: string) => void,
  table: readonly Fixture[],
): Promise<void> => {
  for (const [name, payload, want, needle, absent] of [...shellRows(table), ...cdRows()]) {
    const session = `selftest-codex-${process.pid}-${name}`;
    const [ok, line] = judged(await decideCodex(asCodex(payload, session), ROOT), want, needle, absent);
    rmSync(statePath(session), { force: true });
    report(ok, `codex: ${name}: ${line}`);
  }
};
```
