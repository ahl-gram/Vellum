### Alternatives rejected

- **The press inside `.where`, as the round's mock appended it.** The same geometry (`1254-pr2-probe-line.log`, the mock arm), but the trail block's tail, which `test/site/astro-scaffold.test.ts` reads as empty on every page without an alias line, would carry it, and that test would change for nothing the reader sees.
- **A `line-height` for the press's line, so the Gallery's reserve is a sum of tokens.** The mixed faces of the glyph and the words make the line taller than any line-height set (25.0 and 24.79 against 23.79), off the ruled still; the fitted 1.5rem holds the row at 39.19.
- **`trailPressHref` in `src/layouts/nav.ts`, beside `trailFor`.** `tsconfig.engine.json` checks `src/layouts/**` with no DOM and excludes `src/site/**`; the ladders import DOM code (`explorer-sheet.ts` imports `chart-drawer.ts` and `place-overlay-card.ts`), so the engine pass would follow them in.
- **The press's dress in `src/styles/shared/chart-of-the-atelier.css`**, as the issue body offered for a seat beside the chart of the atelier press. The ruled seat is its own line, not beside it (ruling 3), so the body's other branch, a sheet the press does not share, would hold it; the press is a line of the head cluster, which `src/styles/shared/shell.css` dresses with the trail and the alias line, and `test/site/shell-css.test.ts` already sweeps that sheet's trail rules for a dim ink (T6). A sheet of its own would join the layout's link list and the shared-sheet rosters for 26 lines.
- **The press's dress in `src/styles/shared/primer-hand.css`**, which every ladder room links (BP-H1): the press is the shell's markup on every taught page, and a page that rendered it without that sheet would show it undressed.
- **The press hidden at depth, or while the hand's note is up**: the ruled stills show it at depth (`C-depth-*`) and above the note (`C-press-and-note-*`).
- **`thinTopFaults` reading whether a press is expected from the page itself** (the press's presence in the markup): the check would then pass on a page that lost its press. The caller says, as it says whether the room has an alias line.

     export function spacingOf(press: Box, other: Box): { centre: number; full: number } {
