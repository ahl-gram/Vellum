## The design

1. **`formatSuiteTimings` in `e2e/support/suites.ts` is the one formatter.** Its first parameter widens from
   `readonly E2eSuiteTiming[]` to `readonly { readonly name: string; readonly ms: number }[]` (every `E2eSuiteTiming`
   still fits it), it gains a second parameter `noun = "suite"`, and its head line reads
   `` `per-${noun} wall clock (${timings.length} ${noun}s, ${seconds(total)} total):` ``. Nothing else in the function
   changes, so with the noun left out it returns the same lines as today for every input.
2. **`scripts/unit-file-clock.ts` imports it** from `../e2e/support/suites.ts`. `FileTiming` and `fileClockLines` stay,
   `fileClockLines` becoming one call that renames `file` to `name` and passes `"file"`. The reporter (the default
   export) is unchanged.
3. Nothing reads the unit clock's output differently: the head (`per-file wall clock (N files, S total):`), each row and
   the trailing newline per line are the bytes 53939c6c printed, for every input without a tie. On a tie in milliseconds
   the rows now keep the order the reporter met the files (R4).

**Rejected, with the reason:**

- **A neutral module (`scripts/wall-clock.ts` or `test-support/`) that `suites.ts` imports.** `rulesAt` in
  `scripts/proof-runner/main.ts` copies only `suites.ts` and `skips.ts` into a flat temp folder, so a new run-time
  import in `suites.ts` breaks `npm run proof -- send` and reds `test/repo/proof-runner-rules.test.ts`; fixing it drags
  the proof runner, and its handling of older shas, into this pull request for no behaviour.
- **A generic `formatWallClock(noun, rows)` with `formatSuiteTimings` delegating to it.** Two exports for one format;
  Alex's ruling names `formatSuiteTimings`.
- **Calling `formatSuiteTimings` unchanged and rewriting its head line in the reporter**, or casting a path to
  `E2eSuiteName`: a string patch over another module's output and a lying type.
- **Deleting `fileClockLines` and `FileTiming`.** The reporter would call `formatSuiteTimings` itself, but C2 calls
  `fileClockLines([])`, so a test would change for no behaviour.
- **Adding the tie-break by path to the shared sort.** It changes what the e2e table prints on a tie, which is a change
  to the lanes' output; out of this revision's reach.
- **Keeping the tie-break by path in the adapter (a pre-sort by path before the stable sort).** It keeps a unit-only
  rank rule beside the shared one, which is the duplicate the ruling removes, on a line no test can red (W5 reads none
  at 53939c6c).
- **Printing the unit clock as `per-suite wall clock`.** It would break `1282-after.ts`, T6, C1, C3, the `UNIT_SECONDS`
  bullet's log line, and the CI logs' grep for the unit block against the lanes'.

```ts
import { relative, resolve } from "node:path";
import { formatSuiteTimings } from "../e2e/support/suites.ts";

export type FileTiming = { readonly file: string; readonly ms: number };

type FileEvent = {
  type: string;
  data: { name?: string; file?: string; nesting?: number; details?: { duration_ms?: number } };
};

export const fileClockLines = (timings: readonly FileTiming[]): readonly string[] =>
  formatSuiteTimings(
    timings.map((t) => ({ name: t.file, ms: t.ms })),
    "file",
  );

export default async function* unitFileClock(source: AsyncIterable<FileEvent>): AsyncGenerator<string> {
  const longest = new Map<string, number>();
  for await (const { type, data } of source) {
    if (type !== "test:complete" || data.nesting !== 0 || data.file === undefined || data.name === undefined) continue;
    if (resolve(data.name) !== data.file) continue;
    const file = relative(process.cwd(), data.file);
    longest.set(file, Math.max(longest.get(file) ?? 0, data.details?.duration_ms ?? 0));
  }
  for (const line of fileClockLines([...longest].map(([file, ms]) => ({ file, ms })))) yield `${line}\n`;
}
```

// Usage, from the worktree root: node <this file> <label>
// A mutation whose text is not in the file prints NOT APPLIED and runs nothing; the script exits 1 when a run reds with no named test or a file is not restored.
import { spawnSync } from "node:child_process";
import { readFileSync, writeFileSync } from "node:fs";

const FILES = [
  "test/e2e/suites.test.ts",
  "test/e2e/report-lines.test.ts",
  "test/repo/unit-file-clock.test.ts",
  "test/repo/unit-suite.test.ts",
  "test/e2e/runner.test.ts",
];
type Mutation = { id: string; file: string; find: string; replace: string };
const MUTATIONS: Mutation[] = [
  { id: "none (control)", file: "e2e/support/suites.ts", find: "", replace: "" },
  { id: "W1 head: 'wall clock' becomes 'wallclock'", file: "e2e/support/suites.ts", find: " wall clock (", replace: " wallclock (" },
  { id: "W2 share: toFixed(1) becomes toFixed(2)", file: "e2e/support/suites.ts", find: "share.toFixed(1)", replace: "share.toFixed(2)" },

  { id: "W4 the noun ignored: the head always says suite", file: "e2e/support/suites.ts", find: "`per-${noun} wall clock (${timings.length} ${noun}s,", replace: "`per-suite wall clock (${timings.length} suites," },
  { id: "W5 the branch's tie-break by path dropped from fileClockLines' sort", file: "scripts/unit-file-clock.ts", find: " || (a.file < b.file ? -1 : a.file > b.file ? 1 : 0)", replace: "" },
  { id: "W6 the file clock's noun dropped (default suite)", file: "scripts/unit-file-clock.ts", find: ",\n    \"file\",\n  );", replace: ",\n  );" },
  { id: "W7 the reporter's file filter dropped", file: "scripts/unit-file-clock.ts", find: "    if (resolve(data.name) !== data.file) continue;\n", replace: "" },
  { id: "W8 the reporter's fold: the last event wins", file: "scripts/unit-file-clock.ts", find: "Math.max(longest.get(file) ?? 0, data.details?.duration_ms ?? 0)", replace: "data.details?.duration_ms ?? 0" },
];
const label = process.argv[2] ?? "run";
let bad = false;
const reds = (out: string): string[] =>
  out
    .split("\n")
    .filter((l) => /^not ok \d+ - /.test(l))
    .map((l) => l.replace(/^not ok \d+ - /, ""));
for (const m of MUTATIONS) {
