## The design of r2

**A scripted page answers the read the wait now takes, and each model stages the one state its wait's new term exists for, so the term reds a unit test when it is dropped.**

- **`rest-waits.test.ts`:**
  - `AT_REST` gains `sheetAnims: 0`, so every frame the file scripts carries the field the real `REFIT` returns.
  - `refitFlow` gains a third parameter, `stallsAt`. For the first `STALL_READS` (3) reads after the named press, the page answers the stall r1 measured: the reserve already written at the press, the sheet still at the box it stood in, and `sheetAnims: 1`.
  - Two new tests hold that Z13c reads true through that stall, once at the fold and once at the unfold.
- **`room-waits.test.ts`:**
  - **The scripted page.** `moving` answers any expression that contains `READ`, which takes in `toState`'s `COUNTED`. The three existing `toState` tests give their frames `sheetAnims: 0`.
  - **The `toState` stall.** One new test stages the unfold's stall in the Specimen Book. The map has moved and stands still, and the sheet is read through the slide's first keyframe, at the folded box plus float noise, with `sheetAnims: 1`.
  - **The `foldLanded` model.** One new test stages its two states:
    - the frame laid out before the slide exists (new fit, slip not yet moved, no animation), which r1's slip term is for;
    - a frame the slide stalls in with the slip moved, which only the `sheetAnims` term refuses.

**Rejected:**

- **The fields alone.** That turns the reds green, but M1, M2 and M3 then red nothing (48/48 each), so the term r1 exists for is held by no unit test, and on the runner only by P10, which S13 says may read HOLE.
- **Exporting `COUNTED` from `e2e/suites/specimen/kit.ts` and matching it exactly.** That edits an e2e file r1 built and the implementer ran. Matching by content is the two files' own form: `rest-waits` answers on `expression.includes("--reserve-right")`, and `room-waits`' goto test on `e.includes("getAnimations")`.
- **A `sheetAnims: 0` default in `book`.** It would put a `COUNTED` field on the `READ` answers that `goto` and the `from` read take, a shape the page never returns.
- **A `toState` stall frame at the exact folded box.** Measured a hole (M3 51/51 green).
- **Modelling the frame before the slide in the Z13c and `toState` models.** Two reads in it read the new fit, which is the true rest box (r1's design), so it gives no term anything to refuse.
- **A new test file.** The models live where the waits are already modelled, and `foldLanded` is also SB18's wait, beside `toState` in `room-waits`.
- **Leaving `foldLanded` unmodelled on the ground that its slip term refuses the stall.** F2 shows the slip term needs its own guard, and the stalled frame it cannot refuse is the state r1's staged stall measured (C28).
