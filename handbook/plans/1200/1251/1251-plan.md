## The design

**One reading page, rendered at build time from the guide's data, with a small inlined script for what only the reader's browser knows.** `src/pages/primer/index.astro` calls `primerPage()` (new, `src/site/primer/page.ts`) in its frontmatter; that function reads `LADDERS` and the route tree and returns a view of every room, lesson and step, the index's sections and the count line. Astro renders every room OPEN, every step unsealed and every fold press hidden, so with scripts off the page is the whole guide. The page's own processed `<script>` (`bindPrimer` in `src/site/primer/bind.ts`) then reads the seals, decides which room is open, folds the rest, and wires the fold presses, the hash, the index links and Wipe the slate.

**The script never loads the data.** It imports only `src/site/shared/primer/seals.ts`, `src/site/primer/arrival.ts`, `SEALED` from `src/site/primer/words.ts`, `TOUCH_PRIMARY` from `src/site/shared/chart-touch.ts` and `prefersReduce` from `src/site/shared/reduced-motion.ts`. Measured on the spike build (`out/1251-dry-run/1251-scripts.log`, `node out/1251-dry-run/1251-scripts.ts` after `npm run build` of the spike over `5d8ff76f`): the Primer carries three inline module scripts, the index slip's (2,648 bytes), the shell's (2,362) and its own (2,235), and `dist/_astro/` does not exist. Two earlier spike builds show the two ways it breaks, each a stop condition below:
- importing `deviceStorage` from `src/site/shared/table-store.ts` pulled its grammar's imports in and the page script became an 81,731-byte module file at `dist/_astro/index.astro_astro_type_script_index_0_lang.*.js`;
- importing anything from `src/site/shared/storage.ts`, which the shell's own script already imports through `src/site/shared/shell/desk-notice.ts`, split a 178-byte shared chunk (`dist/_astro/storage.*.js`) and turned the SHELL's script on every page into an external file (`<script type="module" src="/_astro/BaseLayout...js">` on the Q & A and the Glossary too).
So the comment 6754034974 weight never reaches the browser: `HELD_NOTES` and the outline ids are imported only by the build. This is why `seals.ts` does its own guarded storage access instead of importing `storage.ts`.

**Which room is open on arrival** is `roomOnArrival` in `src/site/primer/arrival.ts`, pure: the room holding the element the address's hash names (`/primer/#explorer` from a room's press, Issue #1254; `/primer/#explorer-land` or `/primer/#explorer-islands` from the step note's road back, Issue #1253); else, with any seal stored, the first room with a step that is unsealed AND can apply on this device; else the first room, whose first step is the dice (ruling 16; `test/site/primer-ladders.test.ts` holds the order). A step marked `only: "touch"` applies where `TOUCH_PRIMARY` matches, one marked `only: "motion"` where reduced motion is off; a step that cannot apply never counts as unsealed, since M4 says it is never sealed there and a desktop returner would otherwise resume at the Explorer forever (the Explorer's tablet step).

**The address grammar of the page** (a contract the later subs build to): a room's id is its route's segments joined by `-` (`explorer`, `explorer-portfolio`, `seed-of-the-day`); a lesson's section id is `<room id>-<lesson id>` (`explorer-land`); a step's row id is its step id (`explorer-islands`). `/primer/#<any of these>` opens that room and lands on it.

**One room open at a time.** `open(id)` sets `hidden` on every other room's `.room-body` (its lessons and its next road), shows that room's fold press and marks it `folded`; the room's head and its one-line `what` stay, as `a-folded-full.png` draws. A fold press opens its room and scrolls its head into view. A click on any `a[href^="#"]` (the index slip, the next road, the opening's Try it) opens the room holding its target before the browser follows it, and `hashchange` does the same for back and forward.

**The seals.** `vellum.primer.v1` holds the sealed step ids joined by commas. The page draws a stored step's number as the seal (the class `sealed` on its row), with the seal's words as the number's `title` and, for a screen reader, `role="img"` and `aria-label="<n>, <words>"`. Wipe the slate removes the Primer's key and nothing else, takes every seal off, opens the first room and scrolls to its head. `writeSeal` ships here for Issue #1253's rooms, unused by this page.

```ts
export const PRIMER_STORE_KEY = "vellum.primer.v1";

const STEP_ID = /^[a-z0-9-]+$/;

export function parseSeals(raw: string | null): ReadonlySet<string> {
  if (raw === null) return new Set();
  return new Set(raw.split(",").filter((id) => STEP_ID.test(id)));
}

export const emitSeals = (ids: Iterable<string>): string => [...ids].join(",");

export function readSeals(getStorage: () => Storage): ReadonlySet<string> {
  try {
    return parseSeals(getStorage().getItem(PRIMER_STORE_KEY));
  } catch {
    return new Set();
  }
}

export function writeSeal(getStorage: () => Storage, stepId: string): void {
  if (!STEP_ID.test(stepId)) return;
  try {
    const store = getStorage();
    const sealed = parseSeals(store.getItem(PRIMER_STORE_KEY));
    if (!sealed.has(stepId)) store.setItem(PRIMER_STORE_KEY, emitSeals([...sealed, stepId]));
  } catch {}
}

export function clearSeals(getStorage: () => Storage): void {
  try {
    getStorage().removeItem(PRIMER_STORE_KEY);
  } catch {}
}
```

**`src/site/primer/arrival.ts`**:

```ts
export type Only = "touch" | "motion";

export interface ArrivalRoom {
  readonly id: string;
  readonly steps: readonly { readonly id: string; readonly only?: Only }[];
}

export interface Device {
  readonly touch: boolean;
  readonly motion: boolean;
}

export const applies = (only: Only | undefined, device: Device): boolean =>
  only === undefined || (only === "touch" ? device.touch : device.motion);

export function roomOnArrival(
  rooms: readonly ArrivalRoom[],
  targetRoom: string | null,
  sealed: ReadonlySet<string>,
  device: Device,
): string | null {
  const first = rooms[0];
  if (first === undefined) return null;
  if (targetRoom !== null && rooms.some((r) => r.id === targetRoom)) return targetRoom;
  if (sealed.size === 0) return first.id;
  const unsealed = rooms.find((r) => r.steps.some((s) => !sealed.has(s.id) && applies(s.only, device)));
  return (unsealed ?? first).id;
}
```

What each does, exactly:
- `roomIdOf(route)`: the route's non-empty segments joined by `-`.
- `tryItHref(step)`: split `step.at` at its first `#`; the path must start with `/` or it throws `` `${step.id}'s address is not root-absolute: ${step.at}` ``; returns `` `..${path}${path.includes("?") ? "&" : "?"}step=${step.id}${hash}` `` (relative, the form a page's in-body links take, `handbook/specs/site-architecture.md`, "Link form is scoped"; N9's key `step`).
- `segmentsOf(step)`: walks `step.act`, text between braces as `{ text }`, each braced phrase as a chip for the `words` entry whose `says` equals it (or that has a `match` and whose `says` the phrase starts with): `read: "road"` is `road`, split at the LAST `" The "` into `verb` and `place` (`"Take to The Print Room"` is `Take to` / `The Print Room`; `"Turn The Sheet"` is `Turn` / `The Sheet`; no `" The "` gives the whole text as `verb` and `place` `""`); `read: "option"` is `opt`; a single character from U+2600 to U+27FF is `glyph`; a `words` entry whose `css` contains `.land-end` or starts with `label[`, whose `read` is `"label"`, or whose `css` is `#sizes-label`, is `word`; anything else is `btn` (the round's own rule, `chip` in `design/the-primer/mock/primer.ts`).
- `primerPage(ladders = LADDERS, tree = ROUTE_TREE)`: flattens `seated(ladders, tree)` as each room followed by its subrooms. Each room: `id` from `roomIdOf`; `of` only for a subroom, `OF` of its seat's name from `nameIn` with a leading `"The "` lowered to `"the "`; `entered` only where the ladder has one, through `ENTERED`; lessons numbered with lower-case roman numerals from `i` (`numeral`), each lesson's `id` `` `${room id}-${lesson.id}` ``; steps numbered from 1 in each room, running on across its lessons; each step's `opens` is `OPENS` of the name of the route its `at` opens (the path before any `?` or `#`), its leading `"The "` lowered; `marks` in this order: `touch`, `motion`, `commission` (with `comm: true`), `play`; `next` names the following room in the flattened order, the last room carrying none. `index` is one section per flattened room (`count` its step count, `tone: "sub"` for a subroom, entries `` `${numeral} · ${title}` `` with the lesson ids), then `{ id: AFTERWARD, title: CLOSING_HEAD, entries: [], count: null, tone: "lean" }`. `dateline` is `datelineOf(steps across every flattened room, the number of flattened rooms)`.
- It imports `nameIn` from `ladders.ts` (exported there; a second copy is refused by `vellum/no-word-for-word-copy`, which the spike's lint found).

```ts
import type { IndexSection } from "../../layouts/room-sections.ts";
import { LADDERS, nameIn, ROUTE_TREE, seated, type RouteTree, type Seated } from "../shared/primer/ladders.ts";
import type { Ladder, Step, Words } from "../shared/primer/shape.ts";
import { CLOSING_HEAD, datelineOf, ENTERED, MARKS, OF, OPENS } from "./words.ts";

export type Chip = "road" | "opt" | "glyph" | "word" | "btn";
export type Segment =
  | { readonly text: string }
  | { readonly chip: Chip; readonly text: string; readonly verb?: string; readonly place?: string };

export interface PageStep {
  readonly id: string;
  readonly n: number;
  readonly act: readonly Segment[];
  readonly see: string;
  readonly href: string;
  readonly opens: string;
  readonly only?: "touch" | "motion";
  readonly marks: readonly { readonly text: string; readonly comm: boolean }[];
  readonly commission: boolean;
}

export interface PageLesson {
  readonly id: string;
  readonly numeral: string;
  readonly title: string;
  readonly gloss: string;
  readonly aside?: string;
  readonly steps: readonly PageStep[];
}

export interface PageRoom {
  readonly id: string;
  readonly route: string;
  readonly name: string;
  readonly of?: string;
  readonly what: string;
  readonly entered?: string;
  readonly lessons: readonly PageLesson[];
  readonly next?: { readonly id: string; readonly name: string };
}

export interface PrimerPage {
  readonly rooms: readonly PageRoom[];
  readonly index: readonly IndexSection[];
  readonly dateline: string;
}

export const AFTERWARD = "afterward";
const NUMERALS = ["i", "ii", "iii", "iv", "v", "vi", "vii", "viii", "ix", "x", "xi", "xii"] as const;

export const roomIdOf = (route: string): string =>
  route
    .split("/")
    .filter((p) => p !== "")
    .join("-");

export function tryItHref(step: Step): string {
  const cut = step.at.indexOf("#");
  const path = cut === -1 ? step.at : step.at.slice(0, cut);
  const hash = cut === -1 ? "" : step.at.slice(cut);
  if (!path.startsWith("/")) throw new Error(`${step.id}'s address is not root-absolute: ${step.at}`);
  return `..${path}${path.includes("?") ? "&" : "?"}step=${step.id}${hash}`;
}

const lowerThe = (name: string): string => (name.startsWith("The ") ? `the ${name.slice(4)}` : name);

const chipOf = (w: Words | undefined, text: string): Segment => {
  if (w?.read === "road") {
    const cut = text.lastIndexOf(" The ");
    return cut === -1
      ? { chip: "road", text, verb: text, place: "" }
      : { chip: "road", text, verb: text.slice(0, cut), place: text.slice(cut + 1) };
  }
  if (w?.read === "option") return { chip: "opt", text };
  if (/^[☀-⟿]$/u.test(text)) return { chip: "glyph", text };
  if (
    w !== undefined &&
    (w.css.includes(".land-end") || w.css.startsWith("label[") || w.read === "label" || w.css === "#sizes-label")
  )
    return { chip: "word", text };
  return { chip: "btn", text };
};

export function segmentsOf(step: Step): readonly Segment[] {
  const out: Segment[] = [];
  let at = 0;
  for (const m of step.act.matchAll(/\{([^{}]+)\}/g)) {
    if (m.index > at) out.push({ text: step.act.slice(at, m.index) });
    const phrase = m[1] ?? "";
    out.push(
      chipOf(
        step.words.find((w) => w.says === phrase || (w.match !== undefined && phrase.startsWith(w.says))),
        phrase,
      ),
    );
    at = m.index + m[0].length;
  }
  if (at < step.act.length) out.push({ text: step.act.slice(at) });
  return out;
}

const marksOf = (step: Step): PageStep["marks"] => [
  ...(step.only === "touch" ? [{ text: MARKS.touch, comm: false }] : []),
  ...(step.only === "motion" ? [{ text: MARKS.motion, comm: false }] : []),
  ...(step.kind === "commission" ? [{ text: MARKS.commission, comm: true }] : []),
  ...(step.kind === "play" ? [{ text: MARKS.play, comm: false }] : []),
];

const stepCount = (l: Ladder): number => l.lessons.reduce((n, lesson) => n + lesson.steps.length, 0);

export function primerPage(ladders: readonly Ladder[] = LADDERS, tree: RouteTree = ROUTE_TREE): PrimerPage {
  const flat: { s: Seated; seat: string | null }[] = seated(ladders, tree).flatMap((s) => [
    { s, seat: null },
    ...s.under.map((u) => ({ s: u, seat: s.ladder.route })),
  ]);
  const rooms: PageRoom[] = flat.map(({ s, seat }, i) => {
    const id = roomIdOf(s.ladder.route);
    let n = 0;
    const after = flat[i + 1];
    return {
      id,
      route: s.ladder.route,
      name: s.name,
      ...(seat === null ? {} : { of: OF(lowerThe(nameIn(tree, seat))) }),
      what: s.ladder.what,
      ...(s.ladder.entered === undefined ? {} : { entered: ENTERED(s.ladder.entered) }),
      lessons: s.ladder.lessons.map((lesson, k) => ({
        id: `${id}-${lesson.id}`,
        numeral: NUMERALS[k] ?? String(k + 1),
        title: lesson.title,
        gloss: lesson.gloss,
        ...(lesson.aside === undefined ? {} : { aside: lesson.aside }),
        steps: lesson.steps.map((step) => ({
          id: step.id,
          n: ++n,
          act: segmentsOf(step),
          see: step.see,
          href: tryItHref(step),
          opens: OPENS(lowerThe(nameIn(tree, `${step.at.split(/[?#]/)[0]}`))),
          ...(step.only === undefined ? {} : { only: step.only }),
          marks: marksOf(step),
          commission: step.kind === "commission",
        })),
      })),
      ...(after === undefined ? {} : { next: { id: roomIdOf(after.s.ladder.route), name: after.s.name } }),
    };
  });
  const index: IndexSection[] = [
    ...flat.map(({ s, seat }, i) => ({
      id: rooms[i]!.id,
      title: s.name,
      entries: rooms[i]!.lessons.map((l) => ({ id: l.id, text: `${l.numeral} · ${l.title}` })),
      count: stepCount(s.ladder),
      ...(seat === null ? {} : { tone: "sub" as const }),
    })),
    { id: AFTERWARD, title: CLOSING_HEAD, entries: [], count: null, tone: "lean" as const },
  ];
  const steps = flat.reduce((n, { s }) => n + stepCount(s.ladder), 0);
  return { rooms, index, dateline: datelineOf(steps, flat.length) };
}
```

```ts
import { TOUCH_PRIMARY } from "../shared/chart-touch.ts";
import { prefersReduce } from "../shared/reduced-motion.ts";
import { clearSeals, readSeals } from "../shared/primer/seals.ts";
import { roomOnArrival, type ArrivalRoom, type Only } from "./arrival.ts";
import { SEALED } from "./words.ts";

const ONLY: ReadonlySet<string> = new Set(["touch", "motion"]);
const device = (): Storage => localStorage;

export function bindPrimer(doc: Document = document): void {
  const primer = doc.querySelector<HTMLElement>(".primer");
  if (primer === null) return;
  const rooms = [...primer.querySelectorAll<HTMLElement>("section.room")];
  const idOf = (room: Element): string => room.querySelector("h2[id]")?.id ?? "";
  const arrival: ArrivalRoom[] = rooms.map((room) => ({
    id: idOf(room),
    steps: [...room.querySelectorAll<HTMLElement>("li.step")].map((li) => {
      const only = li.dataset["only"];
      return only !== undefined && ONLY.has(only) ? { id: li.id, only: only as Only } : { id: li.id };
    }),
  }));
  const open = (id: string): void => {
    for (const room of rooms) {
      const on = idOf(room) === id;
      room.classList.toggle("folded", !on);
      const body = room.querySelector<HTMLElement>(".room-body");
      const press = room.querySelector<HTMLElement>(".unfold");
      if (body !== null) body.hidden = !on;
      if (press !== null) {
        press.hidden = on;
        press.setAttribute("aria-expanded", String(on));
      }
    }
  };
  const roomOf = (id: string): string | null => {
    if (id === "") return null;
    const room = doc.getElementById(id)?.closest("section.room");
    return room ? idOf(room) : null;
  };
  const drawSeals = (): ReadonlySet<string> => {
    const sealed = readSeals(device);
    for (const li of primer.querySelectorAll<HTMLElement>("li.step")) {
      const on = sealed.has(li.id);
      li.classList.toggle("sealed", on);
      const num = li.querySelector(".num");
      if (num === null) continue;
      if (on) {
        num.setAttribute("title", SEALED);
        num.setAttribute("role", "img");
        num.setAttribute("aria-label", `${num.textContent}, ${SEALED}`);
      } else {
        for (const name of ["title", "role", "aria-label"]) num.removeAttribute(name);
      }
    }
    return sealed;
  };
  const show = (id: string): void => doc.getElementById(id)?.scrollIntoView({ block: "start", inline: "nearest" });

  const hash = decodeURIComponent(location.hash.slice(1));
  const target = roomOf(hash);
  const sealed = drawSeals();
  const first = roomOnArrival(arrival, target, sealed, {
    touch: matchMedia(TOUCH_PRIMARY).matches,
    motion: !prefersReduce(),
  });
  if (first !== null) {
    open(first);
    if (target !== null) show(hash);
    else if (first !== arrival[0]?.id) show(first);
  }

  doc.addEventListener("click", (e) => {
    const el = e.target instanceof Element ? e.target : null;
    const press = el?.closest(".unfold");
    if (press) {
      const room = press.closest("section.room");
      if (room) {
        open(idOf(room));
        show(idOf(room));
      }
      return;
    }
    const link = el?.closest<HTMLAnchorElement>('a[href^="#"]');
    const room = link ? roomOf(decodeURIComponent(link.hash.slice(1))) : null;
    if (room !== null) open(room);
  });
  window.addEventListener("hashchange", () => {
    const room = roomOf(decodeURIComponent(location.hash.slice(1)));
    if (room !== null) open(room);
  });
  primer.querySelector(".wipe")?.addEventListener("click", () => {
    clearSeals(device);
    drawSeals();
    const home = arrival[0]?.id;
    if (home !== undefined) {
      open(home);
      show(home);
    }
  });
  primer.setAttribute("data-bound", "");
}
```
