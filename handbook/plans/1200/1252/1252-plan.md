## The design

**Data.** Three new files under `src/site/shared/primer/`, each exporting one `Ladder`, copied from the round's `rooms.ts` into the shipped shape by these rules, the same ones Sub 3 used for the Explorer's ladder:

- Every braced phrase has exactly one `words` entry. A control the sentence leans on without bracing it goes in `relies`: Issue #1249 ruling A1, "keep sentences as ruled and put them in the second list".
- Step ids carry their room: `<room>-<round id>`, the room being `roomIdOf` of the route (`prospect`, `reading-room`, `print-room`).
- The round's `eval` and `ticks` acts become shipped acts. The card's eval becomes the Explorer's own `card` click. "Bind, then 40 ticks" becomes `click("#pr-bind")` then `wait("#pr-contents .thumb")`. The road list's `set` becomes `choose`. The round's `forget` and reload are what the walker's `bare()` already does for every step.
- Every word or count a room exports is imported, never typed: `LAY_ON_PAGE`, `layPressFace`, `countLine`, `eraLine`, `ROAD_TAKE`, `ROAD_ASK`, `PACES`, `DEFAULT_PACE`, `POSTER_PRESETS`, `ROAD_PRESETS`, `ROAD_CHOICE`, `pressVerb`, `pressesFor` and `ROUTE_NAMES` (through `roomOf`). So "twice or four times", "2400 pixels", "four sizes" and "Take this road" follow the room when it changes (ruling 10, "the words each room already exports").
- A see-line that quotes the world is held by a `then` read, as `explorer-beasts` holds "Rauhoahai" and `explorer-draw` holds "The Isle of Rahai". The Prospect's year step holds Laukuwelua and its founding year 451. The Print Room's pull step holds The Isle of Rahai, and its road step holds the road from Laukuwelua. A regeneration that renames them reds the step, rather than leaving a stale sentence (`handbook/specs/rulebook.md`, the re-roll sweep).
- A step the round marked "its outcome holds" gets a `do` and a `then`: the year, the lay, the pull, the style and the bind.

The fidelity diff over every reader-visible field reads 0 in all three rooms.

**The list.** `LADDERS` becomes `[EXPLORER, PROSPECT, READING_ROOM, PRINT_ROOM]`: the round's order, with the rooms of pull requests 2 and 3 each inserted at its own place in that order when it lands. The page seats the Prospect under the Explorer through the route tree. The three routes leave `LEFT_UNTAUGHT`. The Primer reads "56 steps in 4 rooms", its index slip carries five rows, and every "Turn the page to" road follows the page's order.

**Two helpers move into `shape.ts`**, so no ladder imports another's file for a word:

  const { evaluate, send, check, settle, stable, goto } = k;
  const rooms = primerPage().rooms.map((r) => r.id);
  const [first, second, third] = rooms;
  if (first === undefined || second === undefined || third === undefined)
    throw new Error(`IX10 reads three rooms, and the Primer carries ${rooms.length}`);
  const others = (open: string): string[] => rooms.filter((id) => id !== open);
  await goto(PRIMER);
  await evaluate(put(PRIMER_STORE_KEY, null));
  await goto(PRIMER);
  const arrived = await settle(FOLD, (d) => d.bound, "primer-bound");
  await evaluate(ARMED);
  const press = await evaluate(AIM(`section.room:has(> .room-head #${second}) .unfold`));
  let folded: Fold | null = null;
  if (press?.hit) {
    await sendClick(send, press.x, press.y);
    folded = await stable(FOLD, "primer-folded", { departed: (d) => d.felt >= 1, same: still });
  }
  const road = folded === null ? null : await evaluate(AIM(`#${second}-steps .next a`));
  let turned: Fold | null = null;
  if (road?.hit) {
    await sendClick(send, road.x, road.y);
    turned = await stable(FOLD, "primer-turned", { departed: (d) => d.felt >= 2, same: still });
  }
  check(
    "IX10 the Primer opens on its first room with every other folded under its press; a real press on the second room's press shows that room's steps, hides the first's and inks it in the index; a real press on its next road does the same for the third room (Issue #1155 ruling 5, Issue #1252)",
    same(arrived.open, [first]) &&
      same(arrived.presses, others(first)) &&
      press?.hit === true &&
      folded !== null &&
      same(folded.open, [second]) &&
      same(folded.presses, others(second)) &&
      same(folded.inked, [second]) &&
      road?.hit === true &&
      turned !== null &&
      same(turned.open, [third]) &&
      same(turned.presses, others(third)) &&
      same(turned.inked, [third]),
    `arrived ${JSON.stringify(arrived)}; press ${JSON.stringify(press)}; folded ${JSON.stringify(folded)}; road ${JSON.stringify(road)}; turned ${JSON.stringify(turned)}`,
  );
}
