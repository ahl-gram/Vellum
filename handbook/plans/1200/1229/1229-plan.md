## The design

**The reveal is a mask.** `inkMask(strips)` in `src/site/ribbon/ink.ts` takes the place of `inkClip` and returns a `mask` shorthand: first `linear-gradient(#000, #000) subtract` (the whole plate, the top layer), then for each strip `i` of `n` one layer `linear-gradient(to top, transparent LO, #000 HI) X Y / W H no-repeat`. The mask's alpha is what of the plate shows, so the whole plate minus the union of the strip layers is what shows; a strip layer is opaque where its strip is still hidden. The composite order is the CSS one: the whole-plate layer, listed first, is subtracted against the union (`add`, the default) of the layers below it, which is today's even-odd polygon (the whole plate with one hole a strip) expressed as a mask.

- **The box.** Each layer covers the strip's hidden box exactly as `inkClip`'s hole did: `L = x0 - PAD_X`, `R = x0 + w + PAD_X`, `T = y0 - PAD_TOP`, `B = y0 + h + PAD_BOTTOM`, each over `RIBBON_W` or `RIBBON_H`, the pads unchanged (7, 4, 2: finding 8). Its size is `pct(R - L) pct(B - T)`; its position is `pct(L / (1 - (R - L))) pct(T / (1 - (B - T)))`, because a mask position's percentage places that fraction of the layer at that fraction of the box (CSS background positioning), so a layer of fraction `w` whose left edge stands at fraction `l` takes the position `l / (1 - w)`. RB21's order, foot, head and colophon reads hold the placement (Tests).
- **The band.** In the layer's own height `hole = h + PAD_TOP + PAD_BOTTOM` plate units (598 on every strip measured), with `p = clamp(0, var(--rb-ink) * n - i, 1)` (the strip's own progress, as the clip had it) and the feather `F = var(--rb-ink-feather)` in plate units, the stops are `LO = (hole * p + F * (p - 1))` and `HI = (hole + F) * p`, each times `100 / hole` percent of the layer. So the band, `F` tall, enters from below the foot at `p = 0` (LO = -F, HI = 0: the strip wholly hidden) and leaves above the head at `p = 1` (LO = hole, HI = hole + F: the strip wholly shown), travelling `hole + F` over the strip's `1 / n` of the run; between, the strip is shown below LO, hidden above HI, and ramps linearly from shown to hidden across the band. A waiting strip is therefore blank paper to its foot and a finished one whole to its head (Issue #432 Q1), which RB21's new foot and head reads hold; the band at `p = 0.5` is centred on the hole's middle for every `F` (finding 9).
- **Order and direction** are today's: strip `i` takes the `i`-th of `n` equal parts of one run, the bottom-left strip first, each from its foot to its head.
- **The feather is a token in the Ribbon's sheet**, `--rb-ink-feather: 300;` in `src/styles/ribbon/index.css`'s `:root` beside `--rb-ink-strip`, a unitless count of plate units, so it scales with the plate under the Glass as the box does, and Issue #1226's feel numbers stay one-line tunes in the sheet. 300, half a strip, is Q1 taken at its recommendation (Open decisions). RB21's 85 and 15 percent rows stay outside the band for any feather under 412 (finding 9), so a later tune past 400 moves those rows in the same change.
- **The pace** is `--rb-ink-strip: 200ms;` (ruled). The run's duration stays `calc(var(--rb-ink-strip) * var(--rb-strips, 3))`.
- **Print** stands the mask down: the sheet's `@media print` block's `clip-path: none !important;` on `#rb-plate` becomes `mask: none !important;` (finding 3). Nothing writes a `clip-path` on the plate any more.
- **What does not change:** the conductor in `src/site/ribbon/app.ts` (which plates ink in, `hold` at Turn about, `retire` at a pick, a lean and a failed draw); `bindInk`, `begin`, `hold`, `retire`, `landing`, the decode wait, the flush before the class, the `animationend` listener; reduced motion taking no reveal at all (`begin` returns before it dresses the plate); a reveal running when reduced motion is turned on collapsing through the blanket; `#map`'s paper ground; the stand-down under the pointer. `clear` removes `mask` where it removed `clip-path`; `dress` writes `mask` where it wrote `clip-path`.

### Alternatives rejected

- **A feathered `clip-path`:** a clip has no soft edge; the issue's own premise.
- **An SVG `<mask>` referenced by `url(#...)`** with a blurred rect per strip: needs inline SVG in the room, against the room's blob `<img>` rule (`src/site/ribbon/app.ts`'s header: "never inline svg: the cross-chart url(#) id rule") and RB11's one face of `#map` (`kids(id("map"), ["rb-inking"])` in `e2e/suites/ribbon/room.ts`).
- **Paper-coloured gradient covers over the strips:** rejected at Issue #432 (RB11's one face; the hover lift moves the plate, not a cover).
- **`element.animate()` driving the mask from script:** the reduced-motion blanket reaches CSS only, so a script animation owes a gate of its own (Issue #432 re-baseline, correction 3).
- **A fixed gradient tile slid by `mask-position`:** a sliding tile leaves its strip's box and would cover the title band or the colophon; a mask layer cannot be clipped to a box other than the element's.
- **Visible-region layers composited by `add`** (the margins, the gaps and each strip's shown part, n + 2 layers): more layers, the same pixel edges, and no one-to-one reading against today's polygon.
- **A deeper foot pad, or the foot cut inside each strip's gradient:** measured; neither clears the foot row everywhere without cutting the colophon somewhere (finding 8).
- **A non-linear ramp** (several stops, an eased band): linear is the boring choice and what the stills show.
- **Overlapping turns** (strip i + 1 starting while strip i's band is still at its head): the ruling keeps strip by strip; 200 ms a strip is each strip's own share of the run.
- **The feather as a TypeScript constant:** the sheet holds the ink-in's feel numbers (`--rb-ink-strip` is there), and a host carries its arrival rules in its own page stylesheet (`handbook/specs/ui-design.md`).
- **Pinning 200 ms or the feather's width in a check:** dressing-level pins lag one live-use cycle (`handbook/specs/conventions.md`); RB21's duration claim keeps reading the token, and its soft-edge claim holds a floor no hard edge reaches and every offered width clears (Tests).

  ```ts
  // The Ribbon ink-in's soft edge, read (Issue #1229): of a strip's middle columns at its half-way frame, the rows that stand part inked, between the same rows on bare paper and on the whole plate.
  import type { Rgb } from "../../support/pixel.ts";

  const PART_INKED = [0.1, 0.9] as const;

  function inkedShare(row: readonly Rgb[], bare: readonly Rgb[], whole: readonly Rgb[], noise: number): number | null {
    let got = 0;
    let full = 0;
    for (let j = 0; j < row.length; j++)
      for (let c = 0; c < 3; c++) {
        got += Math.abs(row[j]![c]! - bare[j]![c]!);
        full += Math.abs(whole[j]![c]! - bare[j]![c]!);
      }
    return full < row.length * noise ? null : got / full;
  }

  export function partInkedRows(
    band: readonly Rgb[][],
    bare: readonly Rgb[][],
    whole: readonly Rgb[][],
    noise: number,
  ): number {
    return band.filter((row, r) => {
      const f = inkedShare(row, bare[r]!, whole[r]!, noise);
      return f !== null && f > PART_INKED[0] && f < PART_INKED[1];
    }).length;
  }
  ```

  `partInkedRows(band, bare, whole, noise)` counts the rows of a block whose blend from the bare frame toward the whole plate, summed over the row's columns and channels, stands strictly between a tenth and nine tenths; a row whose whole plate stands under `noise` per pixel from its bare frame carries no blend and is not counted.
