## What this pull request delivers

When a reader arrives in the Gallery from a Try it on the Primer (`/gallery/?step=gallery-look` or `/gallery/?step=gallery-open`), the room does what the seven rooms before it do: it seats the slim note under the head cluster's trail, seals the step when the room sees it done or used, and drops the key. - The first row of plates keeps its gap under the taller cluster while the note is up (Q2 a).

The Gallery has run no script of its own until now; this pull request gives it one, whose only work is to boot the hand, loaded on every visit (Q3 a). It lists the room in `HAND_ROOMS`. One room remains, the Portfolio, its own pull request (M1); this one leaves Issue #1253 open (C119).

### Alternatives rejected
