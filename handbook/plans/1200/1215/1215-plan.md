## The design

`eventCaption` in `src/itinerary/prose.ts` captions a named crossing with one of the three `NAMED_CROSSINGS` phrasings, each of which writes its own "the" before the river's name. About two thirds of the river templates in `src/society/names.ts` begin "The " (for example `"The % Run"`, `"The %water"`, `"The Waters of %"`), so the caption doubles the article: "a bridge of stone over the The Lemarodorwater".

The fix is one module-private helper in `src/itinerary/prose.ts`, written directly above `NAMED_CROSSINGS`, that writes the name with the phrasing's "the" only when the name does not start with "The " (capital T, then a space), and the three phrasings call it in place of their own "the":

```ts
const the = (r: string): string => (r.startsWith("The ") ? r : `the ${r}`);

const NAMED_CROSSINGS = [
  (r: string): string => `a bridge of stone over ${the(r)}`,
  (r: string): string => `a timber bridge over ${the(r)}`,
  (r: string): string => `here ${the(r)} is crossed by a bridge`,
];
```

Nothing else in the module changes. The fork and the pick in `eventCaption` (the `bridge-` fork keyed on the event's `k`, then `pick(NAMED_CROSSINGS)`) are untouched, so every crossing keeps the phrasing it has today; only the words of a river named "The ..." change. `ENTERED_REALMS` and `ENTERED_WOODS` write no article before the name and are not touched (the existing test "a border's and a wood's caption take one of three phrasings each..." already pins that they never double one).

### Test A

Name: `a named crossing's caption takes one of three phrasings, and a river whose name starts with The keeps that The as its only article`

```ts
test("a named crossing's caption takes one of three phrasings, and a river whose name starts with The keeps that The as its only article", () => {
  const told = (name: string): string[] => [
    ...new Set(captionsAtEachStep((k) => ({ kind: "crossing", dist: 1, k, name, major: true }))),
  ].sort();
  assert.deepEqual(
    told("The Riothi Run"),
    [
      "a bridge of stone over The Riothi Run",
      "a timber bridge over The Riothi Run",
      "here The Riothi Run is crossed by a bridge",
    ],
    "The Riothi Run is written with its own The and no other article",
  );
  assert.deepEqual(
    told("River Skuksvy"),
    [
      "a bridge of stone over the River Skuksvy",
      "a timber bridge over the River Skuksvy",
      "here the River Skuksvy is crossed by a bridge",
    ],
    "River Skuksvy keeps the phrasing's the",
  );
});
```

The exact set is its own premise that all three phrasings are reached: `captionsAtEachStep` (k 0 to 29 on `createRng(7).fork("ribbon-0-5")`) gives "here" at k 0, "a timber bridge" at k 1 and "a bridge of stone" at k 4 (`out/1215-dry-run/1215-captions.log`).
