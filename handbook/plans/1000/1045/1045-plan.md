## The design

**One line, printed by every run before its first suite.** The run's harness start is wrapped, in `e2e/run.ts`, by `fingerprinted` from `e2e/support/fingerprint.ts`: once `start()` in `e2e/harness.ts` resolves, the wrapper reads the browser and prints one stdout line, then hands the context to `runE2e` in `e2e/support/runner.ts`, which runs the suites as today. Every lane child is `e2e/run.ts`, and so is the serial `npm run test:e2e`. On this Mac the line reads (the planner's wired copy, below):

```
fingerprint: darwin 25.6.0 arm64; Node v26.12.1; Brave Browser Chrome/156.0.8078.48; "Chart № 42" 100.31px; № in Palatino; select 34.22px
```

In a lane the driver prefixes it `[A] `, as it does every child line, so a Mac run and a CI run are diffed by eye. Its parts, in order:

1. the system: `process.platform`, `os.release()` (the kernel release, which Node reads without spawning anything: `25.6.0` is Darwin's, not macOS's own number; the CI job's "Set up job" log carries the image name and its Readme) and `process.arch`;
2. `Node` and `process.version`;
3. the browser: the basename of the binary the run launched (`Brave Browser`, `google-chrome`), then `Browser.getVersion`'s `product` (measured: Brave answers `Chrome/156.0.8078.48`, so the product alone never says Brave);
4. the width in px, to two places, of `Chart № 42` set in `#folio-title`'s own lettering (its computed family, size, style, weight and letter spacing);
5. the system face that drew the `№` (`CSS.getPlatformFontsForNode` on a span holding the glyph alone);
6. the height in px, to two places, of a `select.control` alone in its own `.folio-controls` row whose font is the page's `--font-serif-fallback` token.

A part not read prints `unread` (`version unread`, `"Chart № 42" unread`, `№ face unread`, `select unread`) and the line closes with `; unread because <reason>`, the reason cut to its first line (an evaluate's exception text carries its stack, `e2e/harness.ts` line 113), so the line is always one line.

**The probes run on the harness's own first page, after it loads, and leave nothing on it.** `start()` navigates to `/explorer/` and returns; the probe module polls `document.readyState === "complete"` on an `http:` page, then one `Runtime.evaluate` loads the title's face (`document.fonts.load`), adds one hidden fixed box holding two spans and the select row to `document.body`, and returns the two readings; the face call follows; a final evaluate removes the box, always, in a `finally`. The box, the spans and the glyph selector take their ids from exported constants, so the payloads cannot drift apart. The box is `position:fixed;left:0;top:0;visibility:hidden;pointer-events:none`, so it moves no observed element (the page's `ResizeObserver`s watch the head, the folios and the corners, and `bindTopRow`'s `MutationObserver` watches `.corner.tr.folio-room`, none of which the box enters). Measured: 134 ms from `start()` returning to the box removed; after it, the render and health suites on the same tab read 25 of 25 with no console error and no 4xx (Probe readings, below).

**The whole probe is bounded and never throws.** `readBrowserFacts` races the probe against `FINGERPRINT_BOUND_MS`, 5000 ms: swept over eight fresh launches on the Mac, the harness page was ready in 59 to 111 ms and the whole probe took at most 134 ms, so the bound is about 37 times the slowest probe, the headroom left for CI's slower runner. At the bound it hands back every browser fact unread and aborts the probe, which then measures nothing more and only removes its box. Any failure inside (an evaluate that throws, a missing `#folio-title`, a refused CSS call) is caught and named in the facts' `unread`; a refused face call keeps the two readings already taken. The wrapper also catches a probe that throws anyway. So a fingerprint can neither fail a run nor reach `HARNESS ERROR`; it is printed, never judged.

**The probe's time comes before the first suite.** In lane A that suite is the render suite, whose R0 (`check("R0 page loaded + initial auto-draw rendered", await waitReady())`, `e2e/suites/render.ts` line 97) starts its own 15 s (`waitReady` in `e2e/harness.ts`, 200 polls 75 ms apart) after the probe returns. So R0's window is counted 134 ms later on the Mac, and at most 5 s later; a page that boots in 15 to 20 s, which reds R0 today, would pass it. Named as a call (Calls made, 10).

**The line is printed when the harness never comes up too.** A launch failure is the commonest red CI lane in `.claude/skills/vellum-footguns/references/flake-record.md` (its `lane A launch` and `lane B launch` rows, each a `HARNESS ERROR` with no check run), so when `start()` rejects, the wrapper prints the line with the host facts read and every browser fact unread (`unread because the harness stopped before the browser was probed`) and rethrows, and the runner then prints its `HARNESS ERROR` as today. Measured on the planner's wired copy with `VELLUM_BROWSER=/usr/bin/false`: exit 2 after 4.6 s, stdout exactly that one line.

**A failed lane verdict carries it.** The lane driver (`runLane` in `e2e/support/lane-driver.ts`) reads each child line through `laneFingerprint`, as it reads the tally and the skip, and keeps the last fingerprint body in the lane's `LaneResult`. `laneOutcome` in `e2e/support/lanes.ts` appends `  on <body>` to the `LANE ... FAILED` line: the failed lanes' bodies, each distinct body once, in lane order, joined by ` | `, and for a failed lane that printed none, `(lane X printed no fingerprint)`. The `PASS`, `SKIPPED` and `ALL LANES PASS` lines are unchanged.

**Under Issue #1047's flag the line reads the staged layout, and this plan leaves its file alone.** Issue #1047 (merging after this one) registers a new-document style sheet in `e2e/harness.ts` just before the first navigate; this plan has no hunk in `e2e/harness.ts` at all. Its sheet draws the `№` from Times New Roman for text set in the house face and sets `.folio-controls select.control` to 29.21875 px. The title probe copies `#folio-title`'s computed lettering, whose first face is `IM Fell English SC`, and the select probe is a `select.control` in a `.folio-controls` row, so both follow such a sheet: with Issue #1034's version of it staged, the line read `"Chart № 42" 98.03px; № in Times New Roman; select 29.22px` (Probe readings). That the line does not yet say the flag was on is Issue #1047's to add, as a part of the line, since it merges second.

**Why the select probe sets the fallback faces (measured on the Mac only, `out/1045-dry-run/`).** The rooms' own folio selects (the Print Room's `#pr-style`, the Ribbon's `#rb-from` and `#rb-to`, the Specimen Book's `#sb-state`) each lay out 34.22 px tall on this Mac when read alone (`align-self: flex-start`), while a select of the same classes added after load reads 33.22 px in EB Garamond, the face it draws in: the seed input's 33.22, which Issue #1034 measured equal on the Mac and the runner. A select set in `--font-serif-fallback` reads 34.22 px, the rooms' height; and any write to the live `#pr-style`'s `font-family` drops it to 33.22. So on the Mac the rooms' selects stand at the height of the system's fallback face, not the house face, and the probe reads a select in those faces to show the height the rooms stand at; the planner predicts it reads the 29.22 px Issue #1034 saw on the runner. Why the live select keeps that height is not established (the planner's early-insert arm found the faces already loaded at `DOMContentLoaded` and could not reproduce a first layout before them), and the readings are the Mac's alone. Alex ruled this design with that stated (rulings comment 6389488795, question 2), and stop condition 7 hands the plan back if CI's reading does not bear the prediction out.

### Alternatives rejected

- **The probes inside `e2e/harness.ts`**, as the issue's body sketches: the file is 392 lines against the 400 cap (`max-lines` in `eslint.config.ts`), `start()` already hands `evaluate`, `send` and `sleep` to the context a support module takes, and Issue #1047 is about to add a call there; this plan leaves `e2e/harness.ts` untouched.
- **A required `readBrowser` dependency on `runE2e`, printed by the runner**: `test/e2e/runner.test.ts` stands at 398 of `max-lines`' 400 counted lines and its `rig` at 45 of `max-lines-per-function`'s 50 (the plan skeptic's eslint run), so the rig's two new members and the two tests cannot land there without restructuring that file. The wrapper leaves `e2e/support/runner.ts` and its test untouched; what it gives up, the type checker holding `e2e/run.ts` to the wiring, E1 below holds instead, by running `e2e/run.ts`.
- **A fixture page served by the harness** (a route in `e2e/site-server.ts` with the house sheets and a hand-written folio): a second copy of the folio's markup that drifts from the rooms silently, and one more page load per lane.
- **A clone carrying the class `folio-title`** instead of the computed lettering: Issue #1047's staged runner layout restyles `#folio-title` by id, so a class clone would not follow it; copying the live element's computed lettering does (staged reading below).
- **Canvas `measureText` for the title**: no DOM write, but the face call needs a node anyway, and the DOM read matched the live title to 0.02 px.
- **Appending the fingerprint to the child's own `ALL PASS` or `SOME FAILED` line**: `laneCheckTally` reads that line's tally anchored at the line's end, and `test/e2e/runner.test.ts` pins it exactly.
- **A browser check that the line is read** (the issue's optional one): it would turn a diagnostic into a verdict; a probe that cannot read says why on the line itself, which the CI evidence below reads, and E1 drives the real entry point.
- **Pinning the CI Chrome or Ubuntu**: ruled out by Alex (comment 6381406070).

### `e2e/support/fingerprint.ts` (new, about 90 lines)

```ts
import { release as osRelease } from "node:os";
import { basename } from "node:path";
import type { StartOptions } from "../types.ts";
import { errorText } from "./suites.ts";

export const FINGERPRINT_LEAD = "fingerprint: ";
export const NUMERO_TEXT = "Chart № 42";
export const NUMERO_GLYPH = "№";
export const NOT_PROBED = "the harness stopped before the browser was probed";

export interface HostFacts {
  readonly platform: string;
  readonly release: string;
  readonly arch: string;
  readonly node: string;
}

export interface BrowserFacts {
  readonly product: string | null;
  readonly numeroWidth: number | null;
  readonly numeroFace: string | null;
  readonly selectHeight: number | null;
  readonly unread: string | null;
}

export interface EnvironmentFacts extends HostFacts, BrowserFacts {
  readonly binary: string;
}

export const hostFacts = (): HostFacts => ({
  platform: process.platform,
  release: osRelease(),
  arch: process.arch,
  node: process.version,
});

export const unreadBrowser = (reason: string): BrowserFacts => ({
  product: null,
  numeroWidth: null,
  numeroFace: null,
  selectHeight: null,
  unread: reason,
});

const px = (n: number | null): string => (n === null ? "unread" : `${n.toFixed(2)}px`);
const firstLine = (text: string): string => text.split("\n")[0] ?? text;

export function environmentFingerprint(facts: EnvironmentFacts): string {
  const parts = [
    `${facts.platform} ${facts.release} ${facts.arch}`,
    `Node ${facts.node}`,
    `${facts.binary} ${facts.product ?? "version unread"}`,
    `"${NUMERO_TEXT}" ${px(facts.numeroWidth)}`,
    facts.numeroFace === null ? `${NUMERO_GLYPH} face unread` : `${NUMERO_GLYPH} in ${facts.numeroFace}`,
    `select ${px(facts.selectHeight)}`,
  ];
  const tail = facts.unread === null ? [] : [`unread because ${firstLine(facts.unread)}`];
  return FINGERPRINT_LEAD + [...parts, ...tail].join("; ");
}

export const laneFingerprint = (line: string): string | null =>
  line.startsWith(FINGERPRINT_LEAD) ? line.slice(FINGERPRINT_LEAD.length) : null;

export function fingerprinted<C>(
  start: (options: StartOptions) => Promise<C>,
  readBrowser: (ctx: C) => Promise<BrowserFacts>,
  host: HostFacts,
  out: (line: string) => void,
): (options: StartOptions) => Promise<C> {
  const print = (browser: string, facts: BrowserFacts): void =>
    out(environmentFingerprint({ ...host, binary: basename(browser), ...facts }));
  return async (options) => {
    let ctx: C;
    try {
      ctx = await start(options);
    } catch (failure) {
      print(options.browser, unreadBrowser(NOT_PROBED));
      throw failure;
    }
    print(options.browser, await readBrowser(ctx).catch((failure: unknown) => unreadBrowser(errorText(failure))));
    return ctx;
  };
}
```

### `e2e/support/fingerprint-probe.ts` (new, about 120 lines)

```ts
import type { Payload, SuiteContext } from "../types.ts";
import { NUMERO_GLYPH, NUMERO_TEXT, unreadBrowser } from "./fingerprint.ts";
import type { BrowserFacts } from "./fingerprint.ts";
import { errorText } from "./suites.ts";

export type ProbeContext = Pick<SuiteContext, "evaluate" | "send" | "sleep">;
export type Measured =
  | { readonly numeroWidth: number; readonly selectHeight: number }
  | { readonly missing: string };

// Swept 2026-10-24 over eight fresh launches on the Mac: the harness page ready in 59 to 111 ms and the whole probe within 134 ms, so 5 s is about 37 times the slowest, left for CI's slower runner; past it the line prints unread.
export const FINGERPRINT_BOUND_MS = 5_000;
export const READY_POLL_MS = 50;
export const PROBE_BOX_ID = "fingerprint-probe";
export const NUMERO_ID = "fingerprint-numero";
export const GLYPH_ID = "fingerprint-glyph";
export const GLYPH_SELECTOR = `#${GLYPH_ID}`;

export const READY_PAYLOAD =
  `document.readyState === "complete" && location.protocol === "http:"` as Payload<boolean>;

// A room's folio select stands at the height a select set in `--font-serif-fallback` in `src/styles/shared/fonts.css` takes (34.22 px against 33.22 px in EB Garamond on the Mac, measured 2026-10-24), so the probe's row sets those faces to read the height the rooms' selects stand at.
export const MEASURE_PAYLOAD = `(async () => {
  const title = document.getElementById("folio-title");
  if (title === null) return { missing: "#folio-title" };
  const fallback = getComputedStyle(document.documentElement).getPropertyValue("--font-serif-fallback").trim();
  if (fallback === "") return { missing: "--font-serif-fallback" };
  const t = getComputedStyle(title);
  await document.fonts.load(t.fontStyle + " " + t.fontWeight + " " + t.fontSize + " " + t.fontFamily, ${JSON.stringify(NUMERO_TEXT)});
  const box = document.createElement("div");
  box.id = ${JSON.stringify(PROBE_BOX_ID)};
  box.setAttribute("aria-hidden", "true");
  box.style.cssText = "position:fixed;left:0;top:0;visibility:hidden;pointer-events:none";
  const line = (id, text) => {
    const s = document.createElement("span");
    s.id = id;
    s.textContent = text;
    s.style.whiteSpace = "nowrap";
    s.style.fontFamily = t.fontFamily;
    s.style.fontSize = t.fontSize;
    s.style.fontStyle = t.fontStyle;
    s.style.fontWeight = t.fontWeight;
    s.style.letterSpacing = t.letterSpacing;
    const p = document.createElement("p");
    p.appendChild(s);
    box.appendChild(p);
    return s;
  };
  const numero = line(${JSON.stringify(NUMERO_ID)}, ${JSON.stringify(NUMERO_TEXT)});
  line(${JSON.stringify(GLYPH_ID)}, ${JSON.stringify(NUMERO_GLYPH)});
  const row = document.createElement("div");
  row.className = "folio-controls";
  row.style.fontFamily = fallback;
  const select = document.createElement("select");
  select.className = "control";
  select.appendChild(new Option("antique"));
  row.appendChild(select);
  box.appendChild(row);
  document.body.appendChild(box);
  return { numeroWidth: numero.getBoundingClientRect().width, selectHeight: select.getBoundingClientRect().height };
})()` as Payload<Measured>;

export const REMOVE_PAYLOAD =
  `(() => { const box = document.getElementById(${JSON.stringify(PROBE_BOX_ID)}); if (box !== null) box.remove(); return true; })()` as Payload<boolean>;

const versionOf = (ctx: ProbeContext): Promise<string | null> =>
  ctx.send<{ product: string }>("Browser.getVersion").then(
    (v) => v.product,
    () => null,
  );

async function pageReady(ctx: ProbeContext, signal: AbortSignal): Promise<void> {
  for (;;) {
    const ready = await ctx.evaluate(READY_PAYLOAD).catch(() => false);
    signal.throwIfAborted();
    if (ready) return;
    await ctx.sleep(READY_POLL_MS);
  }
}

async function faceOf(ctx: ProbeContext): Promise<string | null> {
  const doc = await ctx.send<{ root: { nodeId: number } }>("DOM.getDocument", { depth: 0 });
  const { nodeId } = await ctx.send<{ nodeId: number }>("DOM.querySelector", {
    nodeId: doc.root.nodeId,
    selector: GLYPH_SELECTOR,
  });
  await ctx.send("CSS.enable");
  try {
    const { fonts } = await ctx.send<{ fonts: readonly { familyName: string }[] }>(
      "CSS.getPlatformFontsForNode",
      { nodeId },
    );
    return fonts.length === 0 ? null : fonts.map((f) => f.familyName).join(" + ");
  } finally {
    await ctx.send("CSS.disable");
  }
}

async function probePage(ctx: ProbeContext, signal: AbortSignal): Promise<BrowserFacts> {
  const product = await versionOf(ctx);
  try {
    await pageReady(ctx, signal);
    const measured = await ctx.evaluate(MEASURE_PAYLOAD, true);
    if ("missing" in measured) return { ...unreadBrowser(`no ${measured.missing} on the page`), product };
    signal.throwIfAborted();
    const face = await faceOf(ctx).then(
      (name) => ({ name, unread: null }),
      (failure: unknown) => ({ name: null, unread: errorText(failure) }),
    );
    const { numeroWidth, selectHeight } = measured;
    return { product, numeroWidth, numeroFace: face.name, selectHeight, unread: face.unread };
  } catch (failure) {
    return { ...unreadBrowser(errorText(failure)), product };
  } finally {
    await ctx.evaluate(REMOVE_PAYLOAD).catch(() => false);
  }
}

export async function readBrowserFacts(ctx: ProbeContext): Promise<BrowserFacts> {
  const stop = new AbortController();
  let timer: NodeJS.Timeout | undefined;
  const gaveUp = new Promise<BrowserFacts>((settle) => {
    timer = setTimeout(() => {
      const reason = `the browser gave no answer within ${FINGERPRINT_BOUND_MS} ms`;
      stop.abort(new Error(reason));
      settle(unreadBrowser(reason));
    }, FINGERPRINT_BOUND_MS);
  });
  try {
    return await Promise.race([probePage(ctx, stop.signal), gaveUp]);
  } finally {
    clearTimeout(timer);
  }
}
```
