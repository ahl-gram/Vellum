## The design

### Half 2: the coast default comes from the engine

`src/terrain/heightfield.ts` gains one exported function directly after the closing `};` of `SHAPES`:

```ts
export function defaultCoastWarp(mapType: MapType): number {
  return SHAPES[mapType].coastWarp;
}
```

`buildHeightfield`'s own fallback, the line `const coastWarp = params.coastWarp ?? shape.coastWarp;` in `terrainSettings` in the same file, is NOT changed. No byte of any chart moves: nothing the generator computes reads the new function.

`src/site/explorer/coast-warp.ts` deletes `DEFAULT_COAST_WARP` and parks the slider at the coast warp the world being drawn falls back to, resolving its map type the way `syncAutoSlider` does:

```ts
export function parkCoastDefault(seed: number, overrides: Partial<WorldRecipe>): void {
  coastSlider.value = String(coastToSlider(defaultCoastWarp(defaultRecipe(seed, overrides).mapType)));
}
```

Its one caller, `draftOverrides` in `src/site/explorer/app-wiring.ts`, passes `seed` and `chosen`, the same pair it already passes to `syncAutoSlider` two lines above.

**Alternatives rejected:**

- **One exported constant in the engine that every `SHAPES` row reads** (`coastWarp: DEFAULT_COAST_WARP`). It removes today's copy but keeps the "uniformly 0.55" assumption the old comment warned about: the day one map type is given its own value, the slider parks at the wrong value again, and Issue #1129's "drop the default from a link" would drop a value that is not that world's default and redraw a different world. The per-type function is exact.
- **Putting `coastWarp` into `defaultRecipe`.** Every recipe would then carry the field, `src/render/recipe-meta.ts` writes `data-vellum-coast-warp` for any recipe that carries one, and every committed chart would change: a regen, for a refactor (`handbook/specs/rulebook.md`, the optional recipe field bullet).
- **Exporting `SHAPES` whole.** Hands the page nine tuning fields to read one.
- **Reading the value off a generated world.** A world build per park, for a number the engine holds as data.
