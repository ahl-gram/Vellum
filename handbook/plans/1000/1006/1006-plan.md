## The design

### A7a, built: the slope field and the landmass labels computed once per world

`generateWorld` in `src/world/generate.ts` computes `slopeField(elev)` and `labelLandmasses(elev, seaLevel)` once, right after the climate, and carries them on its private `Ground` record beside the ground they are read from. `siteStage` hands the slope to `placeSettlements`; `realmStage` hands the slope and the labels to `partitionRealms` and to `buildRoads`. Each of the three takes them as optional fields of its options and computes its own when they are absent, exactly as today: `placeSettlements` through `SiteOptions.slope`, `partitionRealms` through `RealmOptions.slope` and `RealmOptions.landmasses`, `buildRoads` through a new sixth parameter `opts: RoadOptions = {}` with the same two fields.

**Byte identity holds by construction.** `slopeField` and `labelLandmasses` are pure functions of the elevation and the sea level, which are the same objects in all three calls (`terrainStage` makes them, and nothing writes into an elevation field after it: `git grep -nE "(elev|data)\.data\[[^]]*\] *(=[^=]|\+=|-=)|elev\.data\.(fill|set)\(" -- src/hydrology src/climate src/society src/world/generate.ts` prints nothing). Nothing reads either result for writing: `git grep -nE "(slope|landmassIds|lmIds|ids)(\.data)?\[[^]]*\] *(=[^=]|\+=|-=)" -- src` prints only `labelLandmasses`'s own construction in `src/world/landmass.ts` and unrelated arrays in `src/core/mask-components.ts` and `src/hydrology/basins.ts`, and `sizes` is read only (`realmBearingLandmasses` sorts a list of its own). Neither function draws from an rng, so computing them before `siteStage` moves no fork (`handbook/specs/engine-invariants.md`, Fork derivation). And no world computes more than it did: `placeSettlements` always computed the slope and `partitionRealms` always computed the labels, both before any early return.

Rejected, so the builder does not rediscover one:

1. **Required parameters.** One code path, but 47 test call sites of the three functions change (`git grep -c` over `test/`: `placeSettlements` 9 in three files, `partitionRealms` 26 in five, `buildRoads` 12 in two) for no behavioural gain.
2. **The slope and the labels on `World` or on `RealmsResult`.** That changes the type every consumer, the worker's transfer and every close-up builder sees, to save a millisecond; the hoist stays inside `generateWorld`.
3. **A memo keyed on the elevation field.** Cleverness with an invalidation rule; the stage that owns both values can simply pass them.
4. **A helper `reliefOf(elev, seaLevel)` returning both.** Two plain lines in `generateWorld` say the same, and it stays at 43 counted lines, under the lint's 50.

### A4, the road search's arrays (closed by D1)

```
  const done = new Uint32Array(n);
  let generation = 0;
  return (network, start, budget, ride) => {
    const g = ++generation;
    const heap = createMinHeap();
    dist[start] = 0;
    prev[start] = -1;
    seen[start] = g;
    heap.push(start, 0);

    while (heap.size() > 0) {
      const i = heap.pop();
      if (done[i] === g) continue;
      done[i] = g;
      if (network[i]) return { found: i, prev };
      const d = dist[i] as number;
      if (d > budget) break;
      const x = i % w;
      const y = (i / w) | 0;
      for (const offset of NEIGHBORS_8) {
        const nx = x + offset[0];
        const ny = y + offset[1];
        if (nx < 0 || nx >= w || ny < 0 || ny >= h) continue;
        const ni = nx + ny * w;
        if (done[ni] === g) continue;
        if ((data[ni] as number) <= seaLevel) continue;
        let step = offset[2] * terrainCost(ni);
        if (network[ni] || (ride !== undefined && ride[ni] === 1)) step *= REUSE_DISCOUNT;
        const nd = d + step;
        if (seen[ni] !== g || nd < (dist[ni] as number)) {
          seen[ni] = g;
          dist[ni] = nd;
          prev[ni] = i;
          heap.push(ni, nd);
        }
      }
    }
    return { found: -1, prev };
  };
}
```

```ts
// Issue #1006: time `chart --seed N` cold, alternating between two trees, and print each tree's world and render milliseconds as min, median and max.
import { execFileSync } from "node:child_process";
const [base, branch, runsArg, outDir, seedArg] = process.argv.slice(2);
if (!base || !branch || !runsArg || !outDir) throw new Error("usage: node 1006-cli-compare.mts <base root> <branch root> <runs> <scratch dir> [seed]");
const seed = seedArg ?? "42";
const trees = { base, branch } as const;
const world: Record<string, number[]> = { base: [], branch: [] };
const render: Record<string, number[]> = { base: [], branch: [] };
for (let r = 0; r < Number(runsArg); r++) {
  const order = r % 2 ? (["branch", "base"] as const) : (["base", "branch"] as const);
  for (const name of order) {
    const root = trees[name];
    const out = execFileSync("node", [`${root}/src/cli/main.ts`, "chart", "--seed", seed, "--out", `${outDir}/1006-cli-${name}.svg`], { cwd: root, encoding: "utf8" });

  }
}
```
