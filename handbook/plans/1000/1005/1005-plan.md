# Issue #1005: the climate is computed once before the rivers, and only the river bonus after them

**Planned at**: `origin/main` `5ed32b74f27efd0d9e1e7b3cea57b4403bcf2b69`; Issue #1005 comment count 1, the rulings comment below (umbrella Issue #1001: 0). Re-recorded 2026-10-24 after the rulings were folded in; `origin/main` had not moved.
**Rulings**: Alex, 2026-10-24, https://github.com/ahl-gram/Vellum/issues/1005#issuecomment-6380896277: M1 "Yes, build it (Recommended)".
**Open decisions**: none.

Issue #1005 is item A3 of the codebase scan, Issue #1001. Today every world build and every close-up calls `computeClimate` twice on the same ground: once without rivers, to make the rain the rivers are cut from, and once with them. Only the river bonus depends on the rivers, so the second call recomputes the temperature, the wind moisture and the moisture noise from identical inputs. This plan splits `computeClimate` into the part computed once before the rivers and the river bonus applied after them, shares the rain line and the river-cell marker between the world and the close-up, and adds two guard tests for the one place the split can be wired wrong without any existing test noticing. No output byte moves.

## The design

`src/climate/climate.ts` gets two stages and keeps its one-shot entry point:

- `computeDryClimate(elev, seaLevel, seed, opts)` computes everything that does not read the rivers: the temperature, the wind moisture, and the moisture sum, which is the moisture noise plus the wind bonus before any river bonus and before the clamp (`base + windBonus`, the same two terms in the same order as today). It returns the temperature, the river-free moisture (`clamp(sum + 0, 0, 1)`, which is today's first call's moisture) and that sum.
- `withRiverMoisture(dry, riverCells)` measures the distance to the river cells and returns the temperature it was given and the moisture `clamp(sum + riverBonus, 0, 1)`.
- `computeClimate(elev, seaLevel, seed, opts)` keeps its signature and is the two in sequence, `withRiverMoisture` only when `opts.riverCells` is given. Every test and every `design/` archive copy that calls it keeps working unchanged.

**Byte identity holds by construction.** Today the moisture is `clamp(base + windBonus + riverBonus, 0, 1)`, which JavaScript evaluates as `(base + windBonus) + riverBonus`, each step rounded to a double. The split stores `base + windBonus` as a double in a `Float64Array` (a `Field`) and later adds `riverBonus` to it: the same operations on the same doubles in the same order. The river-free moisture is `(base + windBonus) + 0`, exactly as today's first call computes it. The temperature is the same function on the same inputs, now computed once. The fingerprint confirms it: 316 of 316 rows identical, base against trial, and the hero compare 7 of 7 byte-identical.

The world (`hydrologyStage` and `climateStage` in `src/world/generate.ts`) and the close-up (`regionWaters` and `regionClimate` in `src/world/region.ts`) each call `computeDryClimate` once, make the rain from its river-free moisture, cut the rivers, mark the river cells, and hand the same dry climate to `withRiverMoisture`.

Shared, as the issue asks, where the arithmetic is identical:

- **The rain line.** `rain[i] = 0.3 + 1.4 * (preClimate.moisture.data[i] as number);` is the same text at `src/world/generate.ts:108` and `src/world/region.ts:103` (`git grep -n "0.3 + 1.4" -- src` prints exactly those two lines). It becomes `rainFrom(moisture)` in `src/climate/climate.ts`, sized by the moisture field, which is the grid in both callers (the flow rows of the fingerprint are identical).
- **The river-cell marker.** The close-up's `markRiverCells` (`src/world/region.ts:113-119`) rounds each point; the world's loop (`src/world/generate.ts:113-116`) does not. `Math.round` returns an integer unchanged, and every world river point is an integer cell by construction: `riverPoint` in `src/hydrology/rivers.ts` builds each from a cell index as `i % w` and `(i / w) | 0`, and it is the only constructor `extractRivers` uses. Measured: 25,292 world river points over 60 worlds of every band and map type, 0 off an integer cell (`1005-identity-probe.mts`, log `<S>/1005-identity-probe.log`). So on every input the world gives it, the rounding marker computes exactly what the world's loop computes. `markRiverCells` moves, unchanged, to `src/hydrology/rivers.ts` beside the `River` type both callers already import from there.

Rejected, so the builder does not rediscover one:

1. **Recompute only what the second call needs, keeping two calls** (a `skipTemperature` flag, or a cache keyed on the inputs). A flag still recomputes the wind moisture and the noise, which are most of the cost; a cache is cleverness with an invalidation rule to get wrong.
2. **Add the river bonus to the clamped river-free moisture, carrying no sum.** It is byte-identical today, and no fingerprint can tell (mut1 moved 0 of 316 rows), but only because the sum never leaves the clamp's range: it measured 0.12 to 0.88 on 60 worlds and six close-ups. If a later constant change let it leave, the two formulas would part silently. The plan carries the sum so identity holds by construction, not by a range nobody pins. Stop condition S9 refuses this form.
3. **Fold the rain into the dry climate.** The rain is the flow's input, not part of the climate a world keeps; `rainFrom` stays a separate function the two callers call.
4. **Retire `computeClimate` and move its callers to the two stages.** It is called by seven test files and by archive copies under `design/`, and as the one-shot it is the reference the two new tests compare against.
5. **Leave the world's own river-marking loop** (sharing the rain line only). The issue's rule is identical arithmetic, and on every world input it is; keeping a second copy of a four-line loop buys nothing.

```
  const { w, h } = elev;
  const { seed, aspect, map } = frame;
  const { toU, toV } = map;
  return createField(w, h, (x, y) => {
    const u = toU(x);

    const base =
```

```
function moistureField(moistureSum: Field, riverDist: Float64Array | null): Field {
  const { w, h, data } = moistureSum;
  return createField(w, h, (x, y) => {
    const i = x + y * w;
    const riverBonus = riverDist ? 0.3 * (1 - smoothstep(0, 6, riverDist[i] as number)) : 0;
    return clamp((data[i] as number) + riverBonus, 0, 1);
  });
}

export function computeDryClimate(elev: Field, seaLevel: number, seed: number, opts: DryClimateOptions): DryClimate {
  const { w, h } = elev;
  const band = BANDS[opts.band ?? "temperate"];
  const aspect = opts.worldAspect ?? (w - 1) / (h - 1);
  const frame: ClimateFrame = { seaLevel, seed, aspect, map: windowMap(elev, opts) };
  const elevSpan = climateElevSpan(elev, seaLevel, opts.elevSpan);

  const temperature = temperatureField(elev, frame, band, elevSpan);
  const windRain = computeWindMoisture(elev, seaLevel, opts.windDir, !opts.window);
  const moistureSum = moistureSumField(elev, frame, windRain);
  return { temperature, moisture: moistureField(moistureSum, null), moistureSum };
}

export function withRiverMoisture(dry: DryClimate, riverCells: Uint8Array): Climate {
  return { temperature: dry.temperature, moisture: dry.moisture };
}

export function computeClimate(elev: Field, seaLevel: number, seed: number, opts: ClimateOptions): Climate {
  const dry = computeDryClimate(elev, seaLevel, seed, opts);
  return opts.riverCells
    ? withRiverMoisture(dry, opts.riverCells)
    : { temperature: dry.temperature, moisture: dry.moisture };
}

export function rainFrom(moisture: Field): Float64Array {

  for (let i = 0; i < rain.length; i++) {
    rain[i] = 0.3 + 1.4 * (moisture.data[i] as number);
```

```ts
// Issue #1005: hash every output the climate split can reach (a world's climate, biomes, flow, rivers and everything placed on them, its sheets, and its close-ups at every Glass band and at the atlas's plate size), for one tree, so two trees compare in the same environment.
import { createHash } from "node:crypto";

const ROOT = process.argv[2];
if (!ROOT) throw new Error("usage: node 1005-fingerprint.mts <tree root>");
const imp = (p: string) => import(`${ROOT}/src/${p}`);
const { defaultRecipe, generateWorld } = await imp("world/generate.ts");
const { generateRegionWorld, windowAround, regionDetailLevel } = await imp("world/region.ts");
const { createChainCache } = await imp("world/detail-chain.ts");
const { renderMap } = await imp("render/map-renderer.ts");

const h = (v: unknown): string => {
  const hash = createHash("sha256");
  if (typeof v === "string") hash.update(v);
  else if (ArrayBuffer.isView(v)) hash.update(new Uint8Array(v.buffer, v.byteOffset, v.byteLength));
  else
    hash.update(
      JSON.stringify(v, (_k, x) =>
        ArrayBuffer.isView(x) ? Array.from(x as unknown as ArrayLike<number>) : x instanceof Map ? [...x] : x instanceof Set ? [...x] : x,
      ),
    );
  return hash.digest("hex").slice(0, 16);
};

const SEEDS = [42, 7, 1, 3, 11, 99, 123, 2024, 5, 77];
const STYLES = ["antique", "topographic", "ink", "nautical"] as const;
const BAND_SIZES = [0.5, 0.25, 0.125, 0.0625, 0.03125];
const THEMES = ["vegetation", "climate", "moisture", "population"] as const;
const rows: string[] = [];
const row = (label: string, v: unknown): void => {
  rows.push(`${label} ${h(v)}`);
};

for (const seed of SEEDS) {
  const recipe = defaultRecipe(seed);
  const world = generateWorld(recipe);
  row(`world ${seed} ${recipe.band} climate`, [world.climate.temperature.data, world.climate.moisture.data]);
  row(`world ${seed} biomes`, world.biomes);
  row(`world ${seed} flow`, [world.flow.fill, world.flow.dir, world.flow.acc]);
  row(`world ${seed} rivers`, [world.rivers, world.riverCells]);
  row(`world ${seed} labels`, world.realms.labels);
  row(`world ${seed} people`, [world.settlements, world.roads, world.title, world.names, world.beasts]);
  const styles = seed === 42 ? STYLES : (["antique", "topographic"] as const);
  for (const style of styles) row(`svg ${seed} ${style}`, renderMap(world, { style }));
  if (seed === 42 || seed === 7) row(`svg ${seed} legend+arms+beasts`, renderMap(world, { legend: true, arms: true, beasts: true }));
  for (const theme of THEMES) row(`svg ${seed} theme ${theme}`, renderMap(world, { theme }));

  if (seed === 42 || seed === 7 || seed === 3) {
    const cache = createChainCache();
    const capital = world.settlements[0];
    const town = world.settlements[Math.min(3, world.settlements.length - 1)];
    for (const [who, s] of [["capital", capital], ["town", town]] as const) {
      for (const size of BAND_SIZES) {
        const window = windowAround(world, s, size);
        const spec = { window, gridW: 320, gridH: 240, title: "probe", detail: true, chainCache: cache };
        const region = generateRegionWorld(world, spec);
        row(`region ${seed} ${who} ${size} climate`, [region.climate.temperature.data, region.climate.moisture.data, region.biomes]);
        row(`region ${seed} ${who} ${size} waters`, [region.flow.fill, region.flow.dir, region.flow.acc, region.rivers, region.riverCells]);
        row(`region ${seed} ${who} ${size} people`, [region.realms.labels, region.settlements, region.roads, region.region]);
        const regionRecipe = { window, worldGridW: world.recipe.gridW, detail: regionDetailLevel(spec) };
        row(`region ${seed} ${who} ${size} svg`, renderMap(region, { regionRecipe }));
        for (const theme of ["climate", "moisture"] as const) row(`region ${seed} ${who} ${size} theme ${theme}`, renderMap(region, { regionRecipe, theme }));
      }
      const plate = generateRegionWorld(world, { window: windowAround(world, s, 0.38), gridW: recipe.gridW, gridH: recipe.gridH, title: "plate" });
      row(`plate ${seed} ${who} climate`, [plate.climate.temperature.data, plate.climate.moisture.data, plate.biomes, plate.flow.acc, plate.riverCells]);
      row(`plate ${seed} ${who} svg`, renderMap(plate, { style: "antique", legend: true }));
    }
  }
}
console.log(rows.join("\n"));
console.log(`rows ${rows.length}`);
```

### `1005-hero-compare.mts`

```ts
// Issue #1005: render the committed hero chart family from a tree into memory and compare each file with that tree's committed src/static/charts, byte for byte and through the drift guard's own tolerant diff, writing nothing into the tree.
import { readFileSync } from "node:fs";
const ROOT = process.argv[2];
if (!ROOT) throw new Error("usage: node 1005-hero-compare.mts <tree root>");
const { heroChartSvgs } = await import(`${ROOT}/scripts/hero-charts.ts`);
const { diffSvg, DRIFT_TOL } = await import(`${ROOT}/scripts/svg-drift.ts`);
const svgs = heroChartSvgs() as Map<string, string>;
let same = 0;
const differ: string[] = [];
for (const [name, svg] of svgs) {
  const committed = readFileSync(`${ROOT}/src/static/charts/${name}`, "utf8");
  if (committed === svg) {
    same++;
    continue;
  }
  const d = diffSvg(committed, svg);
  const guard = d === null ? "identical" : d.kind === "structure" ? `structure at ${d.at}` : `numbers over ${DRIFT_TOL}px: ${d.overTol}/${d.total}, max ${d.maxAbs.toExponential(2)}`;
  differ.push(`${name} (drift guard reads: ${guard})`);
}
console.log(`hero files ${svgs.size}, identical ${same}, differ ${differ.length}${differ.length ? `: ${differ.join("; ")}` : ""}`);
if (differ.length) process.exitCode = 1;
```

### `1005-cli-compare.mts`

```ts
// Issue #1005: time `chart --seed 42` cold, alternating between two trees, and print each tree's world and render milliseconds as min, median and max.
import { execFileSync } from "node:child_process";
const [base, branch, runsArg, outDir] = process.argv.slice(2);
if (!base || !branch || !runsArg || !outDir) throw new Error("usage: node 1005-cli-compare.mts <base root> <branch root> <runs> <scratch dir>");
const trees = { base, branch } as const;
const world: Record<string, number[]> = { base: [], branch: [] };
const render: Record<string, number[]> = { base: [], branch: [] };
for (let r = 0; r < Number(runsArg); r++) {
  const order = r % 2 ? (["branch", "base"] as const) : (["base", "branch"] as const);
  for (const name of order) {
    const root = trees[name];
    const out = execFileSync("node", [`${root}/src/cli/main.ts`, "chart", "--seed", "42", "--out", `${outDir}/1005-cli-${name}.svg`], { cwd: root, encoding: "utf8" });
    const m = /world (\d+)ms · render (\d+)ms/.exec(out);
    if (!m) throw new Error(`no timing line from ${name}: ${out}`);
    world[name]!.push(Number(m[1]));
    render[name]!.push(Number(m[2]));
  }
}
const q = (a: number[], p: number) => [...a].sort((x, y) => x - y)[Math.floor(p * (a.length - 1))]!;
const fmt = (a: number[]) => `min ${q(a, 0)} median ${q(a, 0.5)} max ${q(a, 1)}`;
for (const name of ["base", "branch"]) console.log(`${name.padEnd(7)} world ${fmt(world[name]!)} | render ${fmt(render[name]!)}`);
console.log(`median world saving ${q(world.base!, 0.5) - q(world.branch!, 0.5)} ms`);
```
