## The design

**On a close-up, a name is never cut by the sheet's edge, a realm name forced into place keeps off the furniture wherever one of its own spots allows, and a realm name takes a spot with no river under it where one is free.** Three placements change, all behind `world.region !== undefined`, so the Glass's sheets and the bound atlas's two regional plates change and no world sheet does (measured: the 100 world sheets of seeds 1 to 100 draw the same bytes under the ruled design).

1. **A realm name slides whole onto the sheet** (ruling, item 1). On a close-up, `placeRealmLabel` tries the same spots it always tried, in the same order (its ladder of five heights at the realm's centre, then up to 240 points of its largest blob nearest the centre), but first slides each spot the shortest straight way that puts the name's box inside the sheet by `SHEET_INSET`, 4 px, the inset place names already keep. A spot whose box already fits does not move.
2. **A realm name steps off its river where it can** (ruling, item 4). Of those slid spots, it claims the first that covers no cell a river of the close-up is drawn through (`boxMeetsRiver` in `src/render/layers/river-clearance.ts`, the test town names already use) before it claims any spot on a river; only where every dry spot is taken does it claim the first it can.
3. **A forced name stays whole, and a forced realm name keeps off the furniture.** When no spot can be claimed, a realm name is forced, as today, but onto the first slid spot clear of the furniture (the cartouche, the scale bar's paper, the key, the compass), and only when none is, onto its centre slid inside the sheet; it still claims its box. A capital's, seat's or town's name that finds no free spot is forced, as today; on a close-up it now takes the first of its eight spots that is off its own mark and inside the sheet, else its first (east) spot as today; it still claims nothing. A furniture test for place names was staged and measured and would never change a spot: none of the 23 forced place names that move has a spot both inside the sheet and clear of the furniture (`out/1105-dry-run/forced-room.txt`), and the 22 of them cut today all have their mark under the key or the cartouche, in a corner at the sheet's edge.

A name whose own mark or realm's land stands under a panel stays there with it, whole and faded (ruling, item 2), and the scale bar's claim stays as it is (ruling, item 3). Nothing else moves: the arena, the order the layers claim in, the place names' river rule, the own-mark refusal and every world-sheet path. The close-up's room for realm names (its furniture and its rivers) is built once in `map-renderer.ts` from the plans `planFurniture` already makes and handed to the realm names; a world sheet hands them none.

## Files

1. **`src/render/layers/sheet-room.ts`** (new, about 25 lines): the room a name has on a sheet. Imports `boxesOverlap` and `type Box` from `../geometry.ts`, `type Projection` from `../transform.ts`.
   - `export const SHEET_INSET = 4;` The inset `inFrame` in `placeSettlementLabel` has always used, unscaled by the sheet's width, as today.
   - `export const FURNITURE_PAD = 2;` The arena's own default pad (`tryClaim(box, pad = 2)` in `src/render/context.ts`).
   - `export function insideSheet(b: Box, proj: Projection): boolean` returns `b.x >= proj.margin + SHEET_INSET && b.x + b.w <= proj.widthPx - proj.margin - SHEET_INSET && b.y >= proj.margin + SHEET_INSET && b.y + b.h <= proj.heightPx - proj.margin - SHEET_INSET`.
   - `export function slideInsideSheet(b: Box, proj: Projection): { readonly dx: number; readonly dy: number }`: with `const lo = proj.margin + SHEET_INSET;`, returns `{ dx: Math.max(0, lo - b.x) - Math.max(0, b.x + b.w - (proj.widthPx - lo)), dy: Math.max(0, lo - b.y) - Math.max(0, b.y + b.h - (proj.heightPx - lo)) }`. A box already inside gets `{ dx: 0, dy: 0 }`. No box is wider than the sheet (the longest realm name swept is 365.2 px against an inset width of 1,356), so no case handles one.
   - `export function clearOfFurniture(b: Box, furniture: ReadonlyArray<Box>): boolean` returns `furniture.every((f) => !boxesOverlap(b, f, FURNITURE_PAD))`.
