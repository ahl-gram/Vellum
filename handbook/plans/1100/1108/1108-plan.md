## What the change does

1. **The scale bar gives way to the title** (D1). Today `planScalebar` (`src/render/layers/scalebar.ts`) always seats the bar at the bottom left, and `planCartouche` (`src/render/layers/cartouche.ts`) can seat the title box over it, drawn later at 0.94 fill opacity, so only a ghost of the bar shows. After: the bar keeps its seat wherever the title's box does not meet its paper. Where it does, the bar takes whichever of two seats covers fewer land cells under its paper: **beside** the title on the bar's own line (its left edge 22 units right of the title box), or **above** the title (its foot 24 units above the title box, its left edge 2 units in from the title's), beside on a tie. Founded charts follow the same rule (D3). This holds on a world sheet and on a close-up alike.
2. **On every world sheet the title finds clear sea** (D2). Today the title takes the corner whose land, sampled on a 16 by 8 grid, is least (`cornerLandFraction`). After: that choice stands wherever its box covers no land cell. Where it covers land, the title takes the first seat whose box covers none, from this list: the four corners in today's order (top right, top left, bottom right, bottom left), then seven seats along the top edge and seven along the bottom, ordered nearest the chosen corner first; tried at full size, then at nine tenths, then at eight tenths of its size. Where no seat is clear even at eight tenths, it keeps the chosen corner at full size. A shrunk title draws everything in it (frame, title, rule, subtitle, founding text, chart number) at its own size. A close-up keeps the chosen corner at full size.
3. **How the two rulings combine.** The bar is planned against the title's final box, after the search has moved or shrunk it (`planFurniture` in `src/render/map-renderer.ts` passes `cartouchePlan.rect`). So a title that leaves the bottom-left corner leaves the bar at home (seed 11: today's title stands over the bar; searched, it moves to the top left at eight tenths and the bar stays home), a title that shrinks in the bottom-left corner still meets the bar's paper and the bar moves (seed 6, shrunk to nine tenths, bar above; seed 35, shrunk to eight tenths, bar beside), and a title that slides onto the bar along the bottom edge moves it the same way. On the 400 plain charts the pair moves the bar on 33 charts, against the 25 whose title stands over it today, with 176 land cells under the moved bars' paper. The sitting's stills showed a title leaving the corner with the bar at home, and shrunk titles in the corner with the bar above and beside (`rec-seed11-every-sheet`, `rec-seed6-every-sheet`, `rec-seed35-every-sheet` and `rec-seed1-every-sheet` in `out/1108/`). A title that slides onto the bar along the bottom edge has no still of its own, but it meets the same two seats D1 ruled, beside on its line or just above it, with nothing new in the geometry, so the combination opens no new question.
4. **Nothing committed moves.** Seed 42's title stands in the top-right corner over no land with its bar at home, so under the ruled pair (`SPIKE_BAR=least SPIKE_LAND=world`) the four committed charts and the og card's chart (seed 42, antique, legend off) render byte-identical to `origin/main` (`out/1108-measure/hero-same.log`, the `least/world` row), and `test/site/hero-charts.test.ts` and `test/site/landfall-prose.test.ts` pass against the committed files under it (Measurements). ## The design

### `src/render/layers/cartouche-seat.ts` (new, about 90 lines)

Owns where the title box may stand and the land count both planners read.

- `export const CARTOUCHE_SCALES = [1, 0.9, 0.8] as const;` and `export type CartoucheScale = (typeof CARTOUCHE_SCALES)[number];`
- `const SEAT_INSET = 20;` (today's `inset` in `planCartouche`, moved here) and `const ALONG_STEPS = 8;` (seven seats between the corners on each long edge).
- `export function landCellsUnder(ctx: RenderCtx, box: Box): number`: the number of grid cells whose elevation is above `ctx.world.seaLevel` and whose projected centre (`ctx.proj.px(gx)`, `ctx.proj.py(gy)`) lies inside `box`, edges included. Read `world.elev.data` at `gx + gy * world.elev.w`; walk only the rows and columns whose centres can fall inside the box.
- `export function cornerSeats(ctx: RenderCtx, width: number, height: number): Box[]`: the four corner boxes in today's order, each `width` by `height`, with `margin = ctx.proj.margin`, `k = ctx.proj.widthPx / 1500` and `inset = SEAT_INSET * k`: top right `{ x: widthPx - margin - inset - width, y: margin + inset }`, top left `{ x: margin + inset, y: margin + inset }`, bottom right `{ x: widthPx - margin - inset - width, y: heightPx - margin - inset - height }`, bottom left `{ x: margin + inset, y: heightPx - margin - inset - height }`. These are exactly today's four corners.
- `function edgeSeats(ctx: RenderCtx, chosen: Box, scale: CartoucheScale): Box[]`: with `width = chosen.w * scale` and `height = chosen.h * scale`, the four `cornerSeats(ctx, width, height)`, then, for `i` from 1 to `ALONG_STEPS - 1`, `x = right + ((left - right) * i) / ALONG_STEPS` (`right` the top-right seat's x, `left` the top-left seat's x), a top seat at the corners' top y and then a bottom seat at their bottom y; those fourteen sorted, stably, by `Math.hypot(seat.x - chosen.x, seat.y - chosen.y)` ascending, after the corners.
- `export function seatOnSea(ctx: RenderCtx, chosen: Box): { readonly rect: Box; readonly scale: CartoucheScale }`: returns `{ rect: chosen, scale: 1 }` when `ctx.world.region !== undefined` or when `landCellsUnder(ctx, chosen) === 0`, tested in that order; otherwise, for each `scale` of `CARTOUCHE_SCALES` in order, the first of `edgeSeats(ctx, chosen, scale)` whose `landCellsUnder` is 0, as `{ rect, scale }`; and where none is found at any scale, `{ rect: chosen, scale: 1 }`.

### `src/render/layers/cartouche.ts` (212 lines, to about 205)

- `CartouchePlan` becomes `{ readonly rect: Box; readonly scale: CartoucheScale; readonly lines: ReadonlyArray<string>; readonly founding: ReadonlyArray<string> }`. The `corner` field is deleted: nothing reads it (`git grep -n "\.corner\b" -- src test test-support e2e scripts` finds no read of a plan's corner; every hit is a CSS class).

### `src/render/layers/scalebar.ts` (144 lines, to about 160)

- Name today's literals: `const BAR_W = 215;`, `const BAR_H = 34;`, `const BAR_INSET = 22;`, `const BAR_FOOT = 24;`, and `const ABOVE_INDENT = 2;`.
- `export function scalebarSeat(ctx: RenderCtx): Box`: today's box exactly, `{ x: margin + BAR_INSET * k, y: heightPx - margin - BAR_FOOT * k - BAR_H * k, w: BAR_W * k, h: BAR_H * k }`.
- `export function planScalebar(ctx: RenderCtx, cartouche: Box): ScalebarPlan` (the second parameter required): `home = scalebarSeat(ctx)`; when `!boxesOverlap(scalebarBacking(home, k), cartouche)` return `{ box: home }`; otherwise `beside = { ...home, x: cartouche.x + cartouche.w + BAR_INSET * k }` and `above = { ...home, x: cartouche.x + ABOVE_INDENT * k, y: cartouche.y - BAR_FOOT * k - home.h }`, and return `{ box: above }` when `landCellsUnder(ctx, scalebarBacking(above, k)) < landCellsUnder(ctx, scalebarBacking(beside, k))`, else `{ box: beside }`. `landCellsUnder` is imported from `src/render/layers/cartouche-seat.ts`.

## The census script (`out/1108-census/census.ts`)

```ts
import { defaultRecipe, generateWorld } from "../../src/world/generate.ts";
import { createProjection, marginFor } from "../../src/render/transform.ts";
import { STYLES, type StyleName } from "../../src/render/style.ts";
import { createRng } from "../../src/core/rng.ts";
import { createLabelArena, type RenderCtx } from "../../src/render/context.ts";
import { planCartouche } from "../../src/render/layers/cartouche.ts";
import { planScalebar, scalebarBacking } from "../../src/render/layers/scalebar.ts";
import { boxesOverlap, type Box } from "../../src/render/geometry.ts";
import type { World, WorldRecipe } from "../../src/world/types.ts";

const FOUR =
  "Where the grey kings sleep under the hill and the river runs backward to the sea, the fishermen of the long coast keep the old count of tides and the older count of the dead.";
const SIX = `${FOUR} No stranger is welcome there, and none who comes ever leaves.`;
const STYLE_NAMES: ReadonlyArray<StyleName> = ["antique", "topographic", "ink", "nautical"];

function ctxOf(world: World, style: StyleName): RenderCtx {
  const proj = createProjection(world.elev.w, world.elev.h, 1500, marginFor(1500));
  return {
    world,
    style: STYLES[style],
    proj,
    coastRings: [],
    elevSpan: 1,
    rng: createRng(world.recipe.seed).fork("render"),
    realmTint: world.realms.seats.map((_, i) => i),
    labels: createLabelArena(),
  };
}

function landUnder(ctx: RenderCtx, r: Box): number {
  const { world, proj } = ctx;
  let n = 0;
  for (let gy = 0; gy < world.elev.h; gy++) {
    const py = proj.py(gy);
    if (py < r.y || py > r.y + r.h) continue;
    for (let gx = 0; gx < world.elev.w; gx++) {
      const px = proj.px(gx);
      if (px >= r.x && px <= r.x + r.w && (world.elev.data[gx + gy * world.elev.w] as number) > world.seaLevel) n++;
    }
  }
  return n;
}

function townsUnder(ctx: RenderCtx, r: Box): number {
  return ctx.world.settlements.filter((t) => {
    const px = ctx.proj.px(t.x);
    const py = ctx.proj.py(t.y);
    return px >= r.x && px <= r.x + r.w && py >= r.y && py <= r.y + r.h;
  }).length;
}

function census(label: string, recipes: ReadonlyArray<WorldRecipe>): void {
  const rows = STYLE_NAMES.map(() => ({ over: [] as number[], onLand: 0, land: 0, towns: 0, shrunk: 0 }));
  for (const recipe of recipes) {
    const world = generateWorld(recipe);
    STYLE_NAMES.forEach((style, i) => {
      const ctx = ctxOf(world, style);
      const plan = planCartouche(ctx);
      const bar = planScalebar(ctx, plan.rect);
      const row = rows[i]!;
      if (boxesOverlap(plan.rect, scalebarBacking(bar.box, 1))) row.over.push(recipe.seed);
      const land = landUnder(ctx, plan.rect);
      row.land += land;
      if (land > 0) row.onLand++;
      row.towns += townsUnder(ctx, plan.rect);
      if (((plan as { scale?: number }).scale ?? 1) !== 1) row.shrunk++;
    });
  }
  STYLE_NAMES.forEach((style, i) => {
    const r = rows[i]!;
    console.log(
      `${label} ${style}: n=${recipes.length} overBar=${r.over.length} [${r.over.join(",")}] onLand=${r.onLand} land=${r.land} towns=${r.towns} shrunk=${r.shrunk}`,
    );
  });
}

const range = (a: number, b: number): number[] => Array.from({ length: b - a + 1 }, (_, i) => a + i);
census("plain 1-400", range(1, 400).map((s) => defaultRecipe(s)));
census("founded four lines 1-100", range(1, 100).map((s) => defaultRecipe(s, { foundingText: FOUR })));
census("founded six lines 1-100", range(1, 100).map((s) => defaultRecipe(s, { foundingText: SIX })));
census("asked 20 alike 1-20", range(1, 20).map((s) => defaultRecipe(s, { mapType: "archipelago", islands: 20 })));
census("asked 20 varied 1-20", range(1, 20).map((s) => defaultRecipe(s, { mapType: "archipelago", islands: 20, isleSize: "varied" })));
census("asked 100 alike 1-20", range(1, 20).map((s) => defaultRecipe(s, { mapType: "archipelago", islands: 100 })));
```
