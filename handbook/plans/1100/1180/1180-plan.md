## The defect, measured

A script that guards its entry with `process.argv[1] === fileURLToPath(import.meta.url)` compares the path it was started by, as typed, with its own real path. Started through a symlink, the two differ, the block is skipped, and the script does nothing and exits 0. For `scripts/unit-suite.ts`, the launcher behind `npm test`, that means a red suite reports green with zero tests run.

`test-support/source-read-guard.ts` has a smaller copy of the same hole. It decides whether to watch a test file by comparing `process.argv[1]`, unresolved, with a root it resolves with `fs.realpathSync`.

## The design

**Each of the 16 entry checks becomes `import.meta.main`. The source-read guard resolves the path it was started by before comparing it with its real root. The lint refuses every read of `process.argv[1]` but the guard's one, so the old form cannot come back.**

- **`import.meta.main`.** It is Node's own answer to "is this module the entry", computed from the resolved main module, and it is the form 14 newer scripts already use. Written once, in Node, it needs no helper, no import and no copy, so `vellum/no-word-for-word-copy` has nothing to compare.
  - Wherever no symlink is involved, it gives the same answer the old comparison did. Spawned by path, it reads true. Imported, run under `node --test` or loaded with `--import`, it reads false.
  - It differs only where the old comparison was wrong: through a symlink.
- **The guard's fix is two lines** (ruling 3):

  ```ts
  const typed = process.argv[1] ?? "";
  const entry = fs.existsSync(typed) ? fs.realpathSync(typed) : typed;
  ```

  - A path that names a file is resolved, so it compares like with like against the resolved root.
  - A path that names none keeps today's value. An empty string still means not watching, and the preload cannot throw at load, which `fs.realpathSync` alone would do for a missing path.
  - It is still one read of `process.argv[1]`. A preload has no other way to learn which file the runner started: `import.meta.main` describes the preload itself, and the main module's path reaches a preload only as `process.argv[1]`.
- **The lint is the class guard** (Gate 1 item 6, Gate 7 item 2).
  - The defect is an entry decided from the path as typed, and `process.argv[1]` is where that path is read. So the rule refuses every read, `process.argv.at(1)` included, the one other spelling a writer would reach for.
  - The guard's one read is counted as allowed. Each half of the work is held by its own check: the lint holds the count, and the guard's own test (T5) holds that the read is resolved before it is compared.
- **The declared Node floor rises to 24.2** (ruling 2), because the design leans on a feature Node added in 24.2.0.
  - On 24.0 or 24.1, `npm test` would exit 0 having run nothing: the defect this issue exists to remove, on another axis.
  - Every machine the house runs on is past 24.2: the Mac (26.13.0), CI (`node-version: '26'` in `.github/workflows/ci.yml`) and the cloud routine (24.22.1 in `scripts/cloud-setup.sh`).

### Rejected alternatives

- **The issue's helper, `isEntry(metaUrl)`, comparing `realpathSync(process.argv[1])` with `fileURLToPath(import.meta.url)`.** It reads false under `--preserve-symlinks-main` (measured above), which makes it a second silent skip. A corrected helper that resolves both sides, as the footgun hook does, is correct, but it adds a module and an import to 16 files to re-derive what Node already computes, so one fact would have two homes. Ruling 1 chose against it.
- **The realpath comparison written in place in each file.** The same objection, written 16 times.
- **A lint rule keyed on equality comparisons with `process.argv[1]`.** It misses the `endsWith` form in `src/cli/main.ts`, any read through a variable, and `pathToFileURL(process.argv[1]).href === import.meta.url`.
- **Dropping the guard's allowance by teaching the rule to accept a read whose value reaches `realpathSync`.** The rule reads syntax, and the guard's read reaches `realpathSync` only through `typed` and an `existsSync` test, so the rule would have to trace a variable. A trace that simple has blind spots of its own, and the behavioural test already holds the resolution.
- **Dropping the allowance by reading the argument another way**, such as `const [, typed] = process.argv`. That passes only by the rule's declared blind spot, which is evasion, not a fix.
- **An ESLint `no-restricted-syntax` selector in `eslint.config.ts`.** `test/repo/lint-wiring.test.ts` refuses any block that sets `no-restricted-syntax`, except the JavaScript refusal and the `design/` exemption. It would also give the rule no fixture test of its own.
- **A unit test that spawns each of the 16 scripts through a symlink.** Most of them do real work: they delete and rebuild `generated/`, rebuild bundles and write face tables. The lint holds the form in every file, today's and tomorrow's. The one behavioural test holds the launcher, the only entry whose silent skip reads as a pass.
- **Converting the footgun hook's two copies.** They are correct, outside the lint's roots, and in Issue #1340's files.

### Created

**`scripts/lint/entry-guard.ts`** (about 50 lines): the rule.

- **`ARGV_PATH_READS`**: `export const ARGV_PATH_READS: Readonly<Record<string, number>> = { "test-support/source-read-guard.ts": 1 };`. It holds the reads of `process.argv[1]` the lint lets stand, counted per repo-relative file.
- **`Shape`**: `type Shape = { readonly type: string; readonly computed?: boolean; readonly name?: string; readonly value?: unknown; readonly object?: Shape; readonly property?: Shape; readonly callee?: Shape; readonly arguments?: readonly Shape[] };`.
  - This is a structural view of an ESTree node, reached by `node as unknown as Shape`, the way `noErrorCast` in `scripts/lint/error-cast.ts` reaches a type node.
  - Do not import `estree` types: `vellum/package-import-declared` refuses an undeclared package.
- **`isProcessArgv`**: `const isProcessArgv = (node: Shape | undefined): boolean`. True for the non-computed member `process.argv`: an object `Identifier` named `process` and a property `Identifier` named `argv`.
- **`isOne`**: `const isOne = (node: Shape | undefined): boolean`. True for a `Literal` whose `value` is the number `1`.
- **`readsTypedEntry`**: `const readsTypedEntry = (node: Shape): boolean`. True for either of two nodes:
  - a computed `MemberExpression` whose property `isOne` and whose object `isProcessArgv` (`process.argv[1]`, `process.argv?.[1]`);
  - a `CallExpression` whose callee is a non-computed `MemberExpression` with property `Identifier` `at` and object `isProcessArgv`, and whose first argument `isOne` (`process.argv.at(1)`).

  Optional chaining needs no extra case, since a `ChainExpression` wraps the same nodes.
- **`noArgvEntryPath`**: `const noArgvEntryPath: Rule.RuleModule`, with `meta: { type: "problem", messages: { typed, stale } }` and no schema, since it takes no options. Its `create(context)`:
  1. computes `const file = repoPath(context.filename)`, with `repoPath` imported from `./source-shape.ts`, and `const tolerated = ARGV_PATH_READS[file] ?? 0`;
  2. keeps `let seen = 0`;
  3. returns visitors for `MemberExpression` and `CallExpression`, both running one `judge(node: Rule.Node): void`. `judge` returns when `readsTypedEntry` is false; otherwise it increments `seen`, and reports `typed` on the node when `seen > tolerated`;
  4. adds a `"Program:exit"` visitor that reports `stale` on the Program node when `seen < tolerated`, with `data: { file, tolerated: String(tolerated), seen: String(seen) }`.
- **`messages.typed`**: `"process.argv[1] is the path the entry was started by, as typed, so started through a symlink it differs from the module's own path and an entry check built on it skips and exits 0 (Issue #1180): a module asks import.meta.main whether it is the entry, and a read that is no entry check is counted for its file in ARGV_PATH_READS in scripts/lint/entry-guard.ts"`.
- **`messages.stale`**: `"{{file}} is counted {{tolerated}} reads of process.argv[1] in ARGV_PATH_READS in scripts/lint/entry-guard.ts and makes {{seen}}, so the count leaves room for a read nobody ruled: lower it, or delete the entry"`.
- **Default export**: `export default { rules: { "no-argv-entry-path": noArgvEntryPath } };`.
- **The C5 stub** has the same exports, `meta` and messages, and its `create()` returns `{}`.
