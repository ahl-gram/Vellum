## The design

**Each of the two switches is held by a helper that switches it back, in the shape of `withScriptsOff` in `e2e/support/scripts-off.ts`.** A new module `e2e/support/network-state.ts` exports `withBlockedUrls` and `withThrottle`, both built on one module-local `holding`: it sends the switch, runs the body, and

- when the body throws, sends the switch back through `bounded` in `e2e/support/runner.ts` (raced against `RESET_BOUND_MS`, its own refusal swallowed) and rethrows the body's own error, so a red names what failed and a browser that has gone cannot hang the suite in its own restore;
- when the body passes, sends the switch back plainly, so a browser that refuses it fails the run loudly rather than leaving every later check blocked or slowed, which is the contract `withScriptsOff` pins ("a restore the browser refuses keeps the body's own error when the body failed, and fails the run when it passed" in `test/e2e/cleanups.test.ts`).

`bounded` gains `export` in `e2e/support/runner.ts`; it is otherwise unchanged and the runner's two rescues keep using it.

**Item 1**: the blocked stretch of `h7Ceremony` (home.ts lines 92 to 99: the block, `h13aPrePaint`, `h13gDoorBase`, `h13bRelease`, `h13cDoorsRead`, `step("H13g")`, the clear) moves verbatim into a new exported `h13DeadBundle(ctx, step)` in `e2e/suites/home/doors.ts`, which returns the doors read, and in the second commit holds the block through `withBlockedUrls`. `h7Ceremony` calls it.

**Item 2**: `h13ePrmNoFlash` holds its throttle through `withThrottle`, around its two navigations and its sampling loop; the loop moves verbatim into a module-local `noFlashSamples` so the nesting stays where it is today, and the throttle values are named `H13E_THROTTLE`. The check, its text and its order are unchanged. It is fixed now although H13e is skipped (C3).

On a passing run both pairs send exactly what they send today, in the same order: the switch, the same stretch, the switch back. Nothing else in the run changes.

   ```ts
   import type { SuiteContext } from "../types.ts";
   import { bounded, RESET_BOUND_MS } from "./runner.ts";

   export type NetworkConditions = {
     readonly offline: boolean;
     readonly latency: number;
     readonly downloadThroughput: number;
     readonly uploadThroughput: number;
   };

   export const NO_BLOCKED_URLS = { urls: [] } as const;
   export const NO_THROTTLE: NetworkConditions = { offline: false, latency: 0, downloadThroughput: -1, uploadThroughput: -1 };

   type Send = SuiteContext["send"];

   async function holding<T>(
     send: Send,
     method: string,
     on: Record<string, unknown>,
     off: Record<string, unknown>,
     body: () => Promise<T>,
     boundMs: number,
   ): Promise<T> {
     await send(method, on);
     let value: T;
     try {
       value = await body();
     } catch (failure) {
       await bounded(send(method, off), boundMs);
       throw failure;
     }
     await send(method, off);
     return value;
   }

   export function withBlockedUrls<T>(
     send: Send,
     urls: readonly string[],
     body: () => Promise<T>,
     boundMs: number = RESET_BOUND_MS,
   ): Promise<T> {
     return holding(send, "Network.setBlockedURLs", { urls }, NO_BLOCKED_URLS, body, boundMs);
   }

   export function withThrottle<T>(
     send: Send,
     conditions: NetworkConditions,
     body: () => Promise<T>,
     boundMs: number = RESET_BOUND_MS,
   ): Promise<T> {
     return holding(send, "Network.emulateNetworkConditions", conditions, NO_THROTTLE, body, boundMs);
   }
   ```
