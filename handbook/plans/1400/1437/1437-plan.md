## The design

One pull request, two commits. The build first takes its own control on main's lockfile (a real install and a build, hashed), then archives this plan, then moves `astro` to 7.4.7 with the exact pinned install above and checks every reading against the control and against this plan's figures. The lockfile's sha is the check that the build resolved what was measured; the `dist/` hash equal to the control's is the check that nothing published moves; `npm audit` printing 0 is the check that the alert's package is cleared. No source, test, spec or workflow file changes.

**The dependency link comes out first.** The build's clone links the main checkout's shared install (`scripts/handoff/slot.ts` line 47, `../../../node_modules`), which every other lane and review sandbox also links. An install run through that link rewrites the shared install, and `npm ci` empties it (`.claude/skills/vellum-footguns/references/held-lines.md`, Issue #783). The footgun hook refuses neither, so the order below is the only guard: the link is removed and its absence read before the first `npm` command that writes.
