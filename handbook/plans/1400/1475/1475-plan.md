## The design

Today a sheet writes its coast `d` into up to nine paths: the three waterline rings (`waterlinesLayer` in `src/render/layers/water.ts`), the land (`landLayer` in `src/render/layers/land.ts`), on a theme plate the field's clip and its redrawn coast stroke (`fieldLayer` in `src/render/layers/field.ts`), the isoline clip on the temperature and rainfall plates (`isoLayer` in `src/render/layers/iso.ts`) and the streak clip on the rainfall plate (`windStreamsLayer` in `src/render/layers/winds.ts`), and on a close-up the land clip (`chartDefs` in `src/render/map-renderer.ts`).

After this change a sheet writes it twice. `chartDefs` opens the sheet's `<defs>` with one unstyled copy, `<path id="coast-H" d="D"/>`, where `H` is the coast `d`'s 32-bit FNV-1a hash (`hashString` in `src/core/rng.ts`) as 8 lowercase hex digits, from a new `coastId(d: string): string` in `src/render/coast.ts`. Every other coast line becomes `<use href="#coast-H" .../>` carrying exactly the attributes its path carries today, in the same order, less `d`. `landLayer` is untouched and keeps its real `<path>` with its own `d`, as ruling 1 says. Each function keeps building its coast string as it does today (`ctx.coastRings.map((r) => pathFrom(r, true)).join("")`); Issue #1476 later builds that string once, and is not running.

Byte for byte, with `D` the coast `d`, `H` its hash, `W` `style.waterline` and `C` `style.coastStroke`:

| where | today | after |
|---|---|---|
| sheet `<defs>`, first child | (nothing) | `<path id="coast-H" d="D"/>` |
| close-up land clip, in `<defs>` | `<clipPath id="region-land-clip"><path d="D" clip-rule="evenodd"/></clipPath>` | `<clipPath id="region-land-clip"><use href="#coast-H" clip-rule="evenodd"/></clipPath>` |
| each of the three rings | `<path d="D" fill="none" stroke="W" stroke-width="9" stroke-opacity="0.16"/>` (5.5 and 0.26, 2.6 and 0.42) | `<use href="#coast-H" fill="none" stroke="W" stroke-width="9" stroke-opacity="0.16"/>` (likewise) |
| land | `<g id="layer-land"><path d="D" fill=... .../>` | unchanged |
| field clip | `<clipPath id="field-clip"><path d="D" clip-rule="evenodd"/></clipPath>` | `<clipPath id="field-clip"><use href="#coast-H" clip-rule="evenodd"/></clipPath>` |
| field coast stroke | `<path d="D" fill="none" stroke="C" stroke-width="1.3" stroke-linejoin="round"/>` | `<use href="#coast-H" fill="none" stroke="C" stroke-width="1.3" stroke-linejoin="round"/>` |
| isoline clip | `<clipPath id="iso-clip"><path d="D" clip-rule="evenodd"/></clipPath>` | `<clipPath id="iso-clip"><use href="#coast-H" clip-rule="evenodd"/></clipPath>` |

```ts
export function coastId(d: string): string {
  return `coast-${hashString(d).toString(16).padStart(8, "0")}`;
```

`src/render/layers/water.ts`, `waterlinesLayer` (signature unchanged), new import `import { coastId } from "../coast.ts";`:

```ts
export function waterlinesLayer(ctx: RenderCtx): SvgNode {
  const { style, coastRings } = ctx;
  const href = `#${coastId(coastRings.map((r) => pathFrom(r, true)).join(""))}`;
  const rings = [
    { width: 9, opacity: 0.16 },
    { width: 5.5, opacity: 0.26 },
    { width: 2.6, opacity: 0.42 },
  ];
  return el(
    "g",
    { id: "layer-waterlines" },
    rings.map((r) =>
      el("use", {
        href,
        fill: "none",
        stroke: style.waterline,
        "stroke-width": r.width,
        "stroke-opacity": r.opacity,
      }),
    ),
  );
}
```

`src/render/map-renderer.ts`, `chartDefs`, `coastId` added to the existing import from `./coast.ts`:

```ts
function chartDefs(ctx: RenderCtx): SvgNode {
  const { world, style, proj, coastRings } = ctx;
  const margin = proj.margin;
  const coastD = coastRings.map((r) => pathFrom(r, true)).join("");
  const id = coastId(coastD);
  return el("defs", {}, [
    el("path", { id, d: coastD }),
    el("clipPath", { id: "map-clip" }, [
      el("rect", {
        x: margin,
        y: margin,
        width: proj.widthPx - 2 * margin,
        height: proj.heightPx - 2 * margin,
      }),
    ]),
    ...(world.region
      ? [el("clipPath", { id: "region-land-clip" }, [el("use", { href: `#${id}`, "clip-rule": "evenodd" })])]
      : []),
    ...(style.glyphs ? glyphSymbolDefs(style) : []),
    ...textureDefs(ctx),
  ]);
}
```

No other source line changes, and no comment is added: the tests below are the record. Every file stays far under 400 lines.

### Alternatives rejected

- **A fixed id, `coast`, as the issue's "house form" line suggests.** Rejected on a measurement. The Explorer mounts a close-up inline in the same document as the world sheet (`commitInset` in `src/site/explorer/lod-controller.ts` sets `el.innerHTML = res.svg` on a `.region-inset` inside `#map`), and an `href="#..."` resolves to the first element in the document carrying that id. With a fixed id, a seed 42 close-up drawn below its world sheet in one page differs from the same close-up alone by 51,899 pixels (its rings draw the world's coast); with the hashed id, by 0 (`out/1475-dry-run/inset.log`). The fixed id is commit 2's stub, so the test that refuses it is seen to red.
- **The coast lines pointing at the land path.** A `<use>` cannot override a fill or stroke written on the element it points at, and the arrival ceremony's dash on the land path (`dashCoastForInk` in `src/site/explorer/draw-ceremony.ts`) would show on every line drawn from it.
- **The copy inside the waterlines group's own `<defs>`.** That was the planner's first call, when the rings were its only reader; ruling 3 makes eight lines in five functions read it, and a copy in the sheet's own `<defs>` keeps each of them independent of another layer's output. Proven by the same pixel comparison (below).
- **An id built from the sheet's identity (seed, overrides, window, band, width).** It has to name every input that moves the coast, and one missed input gives two different coasts one id. The hash of `d` is the coast's identity.
- **A counter per render.** Not the same bytes from one render to the next.
- **The coast string built once on the render context.** That is Issue #1476's work, ruled byte-safe only; this plan leaves each function's string where it is.
- **The land drawn from the copy too.** Ruled out (ruling 1).

```ts
// Issue #1475 evidence: each new sheet must be its old sheet with every coast path but the land's drawn from one copy opening the sheet's defs, byte for byte.
import { readFileSync, readdirSync } from "node:fs";
import { hashString } from "../../src/core/rng.ts";

const DIR = "out/1475-pixel/sheets";
const LAND = '<g id="layer-land">';

export function expectedFrom(old: string): string {
  const d = new RegExp(`${LAND}<path d="([^"]*)"`).exec(old)?.[1];
  if (d === undefined || d.length === 0) throw new Error("the old sheet's land opens on no coast path");
  const id = `coast-${hashString(d).toString(16).padStart(8, "0")}`;
  const path = `<path d="${d}"`;
  const landAt = old.indexOf(LAND + path) + LAND.length;
  let out = "";
  let from = 0;
  let drawn = 0;
  for (let at = old.indexOf(path); at !== -1; at = old.indexOf(path, at + path.length)) {
    out += old.slice(from, at) + (at === landAt ? path : `<use href="#${id}"`);
    if (at !== landAt) drawn++;
    from = at + path.length;
  }
  out += old.slice(from);
  if (drawn < 3) throw new Error(`only ${drawn} coast paths besides the land`);
  const defsAt = out.indexOf("<defs>") + "<defs>".length;
  if (defsAt < "<defs>".length) throw new Error("the sheet holds no <defs>");
  return `${out.slice(0, defsAt)}<path id="${id}" d="${d}"/>${out.slice(defsAt)}`;
}

if (import.meta.main) {
  let bad = 0;
  for (const file of readdirSync(DIR)
    .filter((f) => f.endsWith("-old.svg"))
    .sort()) {
    const name = file.replace(/-old\.svg$/, "");
    const want = expectedFrom(readFileSync(`${DIR}/${file}`, "utf8"));
    const got = readFileSync(`${DIR}/${name}-new.svg`, "utf8");
    let at = 0;
    while (at < want.length && want[at] === got[at]) at++;
    const same = want === got;
    if (!same) bad++;
    console.log(
      same
        ? `same     ${name} (${Buffer.byteLength(got)} bytes, ${got.split('href="#coast-').length - 1} references)`
        : `DIFFERS  ${name} at ${at}: expected ...${want.slice(Math.max(0, at - 60), at + 60)}... got ...${got.slice(Math.max(0, at - 60), at + 60)}...`,
    );
  }
  process.exitCode = bad === 0 ? 0 : 1;
}
```
