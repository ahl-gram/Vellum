## Files

### The plate face (the lettering)

- **Source faces** [D9]: the three woff2 files `im-fell-dw-pica-latin-400-normal.woff2`, `im-fell-dw-pica-latin-400-italic.woff2`, `im-fell-dw-pica-sc-latin-400-normal.woff2` (fontsource 5.3.0, OFL) and their OFL text in `design/kit/plate-fonts/`, inside the kit but outside `design/kit/fonts/`, which `scripts/kit-fonts.ts` copies to the served `public/fonts/`.
- **`scripts/plate-face.ts`** (new): reads the faces with `fontkit` (already a devDependency, `scripts/glyph-outline.ts` is the precedent), takes the plate subset, flattens each quadratic at 8 steps, simplifies by Ramer-Douglas-Peucker on SQUARED distances (no `Math.hypot`, so a regenerate on linux CI matches a Mac byte for byte), rounds to the ruled grid [D8], writes relative path data, reads kerning as `layout(a + b)` against the plain advances and the standard ligatures (`liga` only: no contextual alternates, the lib spike's opentype.js rendering Alex ruled from), and writes the data modules below. No new dependency.
- **`src/prospect/letter/face-italic.ts`, `face-caps.ts`, `face-roman.ts`** (generated, one glyph or one kern row per line, each under the 400-line bound): glyph id, advance, path data; kern pairs grouped by the left glyph (read with `{ liga: false }`, so a ligature does not swallow a pair); ligature substitutions. Named "the plate face", never "IM Fell DW Pica", which the OFL reserves for the original (clause 3). The OFL notice must travel with every copy (clause 2), and the bundler strips comments (plan skeptic: the first-line comment of `prospect-job.ts` counts 0 in the built bundles), so the notice travels three ways: the face's copyright line and the OFL text appended to the site's served licence roll, `design/kit/fonts/OFL.txt` (served as `/fonts/OFL.txt`), under a heading saying the prospect plates' lettering is a modified version prepared from it; a `/*! ... */` legal comment at the head of each face module; and an exported notice string the letter module carries. Evidence: a grep of the built `worker.bundle.js` and `chunks/worker-client.js` for the notice.
- **`src/prospect/letter/numero.ts`** (hand-authored data): the ruled "№" [D7], one outline in font units, used by the caps and roman faces.
- **`src/prospect/letter/letter.ts`**: `letterRun` lays a run out (kerning, ligatures, the SVG letter-spacing after each glyph, `text-anchor` start, middle or end) and returns the `<use>` placements plus the run's true width; a per-plate collector defines each distinct glyph once in `<defs>` with the plate's id suffix (the atlas and a page may hold more than one plate). Face rule from the lib spike: italic for an italic run, small capitals for a run whose letters are all capitals, roman otherwise; optical scales roman 1.06, caps 1.0, italic 1.1. Each lettered run is a `<g aria-label="the words">`, so the words survive for a reader of a standalone SVG and for the tests and the e2e suite that read them. A character outside the table throws `RangeError`, since the coverage test below proves none reaches it.
