## The procedure, on the CI proof runner

1. The archived plan is committed and pushed alone; the checks are written and committed with every unit test still in place, and pushed.
2. Locally, one suite at a time, each to completion: every touched suite unmutated on the branch, the lane pairs (`hunt,print-room,room-address`; `prospect,ribbon,broadside`; `chart-drawer,document-rooms`), and the probes the designs name before the runner (PR24d's revoked blob, PR37's font timing, PR39's write count, the Prospect's back/forward cache).
3. The proof list is a module exporting `MUTATIONS` (the lane's scratch file `779-2g-proofs.ts`), each entry `{id, edits, unit: {files, expect}, e2e: {suites, expect}}` naming the unit test's full name and every check the mutation must red, sent with `npm run proof -- send <list>` from the pushed head, under 256 jobs a send (controls included), and read with `npm run proof -- read <run>`. Controls are per selection (`keyOf` in `scripts/proof-runner/ledger.ts`), so a CD44 or CD25 flake in the `chart-drawer` control voids only that selection's rows, which are re-sent; a flake is a row in `.claude/skills/vellum-footguns/references/flake-record.md`, never a proof result.
4. BITES is proof. IMPRECISE is read: where every extra check reads the same broken thing, the row is re-sent with that set named; otherwise the check or the mutation is wrong and is fixed. HOLE means the claim is unheld: the check is widened and re-proven, or the claim keeps its unit test for 2i. NEEDS READ is read from the ledger's stanza under 6090198881's terms. Green arms run locally (above).
5. The deletions and shrinks are the next commit; then `MEASURED_SECONDS`, the size list, errata and specs.
6. `vellum-guard-prover` gets its one round on the new checks at the pushed head (workflow step 11), handing back its mutation list, which this lane sends to the runner; the cold `vellum-pr-skeptic` follows once the pull request is open; a guard changed after either round is proven by this lane on the runner and named so (step 15).

**Every new group undoes what it changes in a `finally`** (2f's rule): emulated media, metrics, scripts, a hover, a focus, a scroll, a zoom, an open slip, a stored table, an injected script.
