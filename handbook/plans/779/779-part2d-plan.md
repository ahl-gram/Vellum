### 2d-rules: the 17 rows become lint rules

The CSS the TypeScript builds is linted by `test/repo/css-beyond-sheets.test.ts`: it runs each TypeScript `SRC_CSS` entry (`GALLERY_PAGE_CSS`; both atlas dresses' style blocks from `atlasDocument`; og-card's faces from `fontFaceCss`), lints each through the stylesheet block's own rules and options (imported from `eslint.config.ts` by name, applied at the virtual path `<source>/<n>.css` with `overrideConfigFile: true`) with `allowInlineConfig: false`, asserts each source yields non-empty CSS carrying a named rule of its own (the gallery's `figure img:hover`, the atlas's `.atlas-sheet figure a img:hover`, og-card's `@font-face`), so an extraction miss cannot pass on nothing, refuses any `SRC_CSS_FILES` entry that is not a TypeScript module (a page's CSS lives in a sheet under `public/` since D1 C, so a new `.astro` `<style>` is refused there rather than read), and asserts no message from the 2d rules (the existing comment rules would report on the atlas's shipped comments, whose bytes `DOWNLOAD_SHA256` pins; that gap becomes one `handbook/errata/` row).
