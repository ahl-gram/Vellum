## Decision for Alex

**D1. The Specimen suite's five unstepped calls that can throw.** The rule ruled in M5 finds, besides the Running Head's one, five calls in the Specimen suite's main sequence that can throw (each samples the page's pixels through a helper that throws if it cannot read the page) outside every step. Stepping them would also contain the member reads around them, which Alex chose not to do in Issue #654's decision A (2026-10-01, the PR #725 errata row), when stepping was offered for the sake of changing nothing else that runs.
- (A, recommended) Step them: the Specimen's lean-state group (SB5 and its parts) runs inside one step, the suite is run, and the PR #572 errata row on these calls leaves. A failure there then names its check instead of stopping the suite. The rule then loses no call the current test holds.
- (B) Leave the Specimen as decision A left it: the rule takes an exact-text excuse list for those five calls, each excuse reding if its call changes or goes, and the errata row stays, narrowed to the Specimen.
- (C) The rule stops at destructured kit members: simpler, but it then loses 129 of the 507 calls the current test holds (measured), groups in survey, prospect, ribbon, broadside, verso, zoom, chart-drawer and cards among them, the same order as M5's option B, which Alex did not take.

A fourth path, the Specimen fixed in a pull request of its own first, is not offered: the rule cannot land green until the Specimen is settled one way or another, so it would only split option A or B across two reviews.
