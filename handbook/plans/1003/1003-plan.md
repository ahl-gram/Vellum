## The design

### What changes, in one paragraph

A new pure module, `src/site/shared/address-grammar.ts`, is the one home of the address's world grammar: the style, map type, climate band and theme lists (each built from a `Record` over its type, so the type checker refuses a list that misses or invents a member), the land and coast ranges, a list reader `oneOf`, land and coast readers that take the seed's digit grammar and clamp, and two readers of a whole set of keys, `readWorldKeys` (seed, style, type, band, land, coast) and `readDressKeys` (theme and the three dress flags). Every room's address parser is built on them: the Ribbon's and the Prospect's add their own keys, read the same way; the Print Room's moves out of its controller into `src/site/print-room/address.ts`; the Reading Room's moves out of its controller into `src/site/reading-room/address.ts`. The Explorer's link reader takes land and coast through the shared readers, its two sliders take their limits from the shared ranges, and the Chart Table's grammar takes its lists, ranges and readers from the same place. The live year reads through `parseYear`. So everywhere a link is read, only a run of digits is a number and an empty key is no key: an empty `#seed=` is today's seed, an empty `#land=` the world's own waterline, an empty `#coast=` the default warp, and `year=1e3` no year.

### Why this shape, and the alternatives rejected

- **The shared readers take the seed's grammar through `seedFromHash` itself**, imported from `src/site/explorer/address.ts` where it stays (ruled). One digit grammar, one pin (`test/site/hash-seed-gate.test.ts`). The Ribbon's `a` and `b`, the Prospect's `i`, the Chart Table's `nat` and every land and coast reader go through it; no second `/^\d+$/` remains in a reader.
- **`emitTableKey` moves from `src/site/explorer/address.ts` into `src/site/shared/table-address.ts`.** With the rulings as written, `address-grammar.ts` imports `src/site/explorer/address.ts`, and `table-address.ts` imports `address-grammar.ts`; `explorer/address.ts` imports `table-address.ts` today only for `emitTableKey` (`TABLE_KEY`, `emitTable`, `type TableItem`), so leaving it would make `table-address.ts -> address-grammar.ts -> explorer/address.ts -> table-address.ts` the first value-import cycle under `src/`. Every use across that cycle would sit inside a function, so it would run, but which module evaluates first would then depend on which page imports which first, and the first top-level use of a list would throw at load on one page and not another. `table-address.ts` is the table key's own grammar (`TABLE_KEY`, `emitTable` and `tableHash`, whose comment already states the empty-table rule `emitTableKey` keeps), so it is the function's natural home. Rejected: leaving the cycle; a second copy of the digit grammar in `address-grammar.ts` (the drift this issue closes, and against the ruling that the new file imports `seedFromHash`); moving `emitTableKey` into `src/site/explorer/hash-sync.ts`, its one caller (the table's rule then lives in the Explorer's DOM bridge, where no node test reaches it).
- **The lists are `Object.keys` of a `Readonly<Record<Name, true>>`.** An object literal of that type must name every member of the union and no other, so `npm run check` refuses a list that drops or invents a style, a map type, a band or a theme (`handbook/specs/check-placement.md`, "Make a wrong state unrepresentable before testing that it does not occur"). Rejected: `readonly StyleName[]` literals, which refuse an invented member but not a missing one; importing the engine's own keyed records (`STYLES` in `src/render/style.ts`, `THEMES` in `src/render/layers/field.ts`) into page bundles, which ships their palettes and specs to pages that only need the names.
- **The Explorer keeps its own allowlists for style, type, band and theme**: `readHash` in `src/site/explorer/hash-sync.ts` validates those against its `<select>` elements' options, which the lists mirror, and an absent key resets each select to its empty option; reading them through `readWorldKeys` would change both behaviours for no defect. Only land and coast, the defect, move there. Its flags stay inline (`legend === "1"`), the same rule `readDressKeys` keeps.
- **The Reading Room's and the Print Room's parsers are pure modules with unit tests** (D1, and D2's option as offered): their controllers look elements up and await the worker at import, so no node test can import them, and `handbook/specs/check-placement.md` puts what a parser returns for an input in the unit suite. Rejected: a browser check sending a malformed link to each room (browser-only, and it moves each suite's seconds, which owes a `MEASURED_SECONDS` re-read from CI's lane logs, `handbook/specs/site-architecture.md`).
- **Each room keeps its own parser and its own test**, built on the shared readers, rather than every room calling `readWorldKeys` from its controller: each room's grammar stays named and pinned where its page reads it, and a room that stopped delegating reds its own test.
- **`parseLive` takes the year through `parseYear`** exactly, its nine-digit ceiling and its trim included: the issue's stated change, and the grammar the Prospect's year control and the Chart Table already share. See "Calls made" C2.
- **The two lists of non-numbers live in `test-support/`** and every reader's test imports them (Gate 1 items 8 and 16).
- **The writers are untouched.** The four hash writers' `Math.round(land * 1000)` and `Math.round(coast * 100)` and the table's `worldFields` write digits already; the issue names readers, lists and limits, not writers.

  import type { StyleName } from "../../render/style.ts";
  import type { MapType } from "../../terrain/heightfield.ts";
  import type { ClimateBand } from "../../climate/climate.ts";
  import type { ThemeName } from "../../render/layers/field.ts";
  import { seedFromHash } from "../explorer/address.ts";

  const STYLE_KEYS: Readonly<Record<StyleName, true>> = { antique: true, topographic: true, ink: true, nautical: true };
  const TYPE_KEYS: Readonly<Record<MapType, true>> = { island: true, archipelago: true, continent: true, citystate: true };
  const BAND_KEYS: Readonly<Record<ClimateBand, true>> = { temperate: true, tropical: true, polar: true };
  const THEME_KEYS: Readonly<Record<ThemeName, true>> = { vegetation: true, climate: true, moisture: true, population: true };

  export const STYLE_NAMES = Object.keys(STYLE_KEYS) as readonly StyleName[];
  export const MAP_TYPES = Object.keys(TYPE_KEYS) as readonly MapType[];
  export const CLIMATE_BANDS = Object.keys(BAND_KEYS) as readonly ClimateBand[];
  export const THEME_NAMES = Object.keys(THEME_KEYS) as readonly ThemeName[];

  export const LAND_MIN = 0.1;
  export const LAND_MAX = 0.7;
  export const COAST_MIN = 0;
  export const COAST_MAX = 1;

  export interface WorldKeys {
    readonly seed: number | null;
    readonly style: StyleName | null;
    readonly type: MapType | null;
    readonly band: ClimateBand | null;
    readonly land: number | null;
    readonly coast: number | null;
  }

  export interface DressKeys {
    readonly theme: ThemeName | null;
    readonly legend: boolean | null;
    readonly arms: boolean | null;
    readonly beasts: boolean | null;
  }

  export function oneOf<T extends string>(raw: string | null, list: readonly T[]): T | null {
    return raw !== null && (list as readonly string[]).includes(raw) ? (raw as T) : null;
  }

  const scaled = (raw: string | null, divisor: number, lo: number, hi: number): number | null => {
    const n = seedFromHash(raw);
    return n === null ? null : Math.min(hi, Math.max(lo, n / divisor));
  };

  export const landFromAddress = (raw: string | null): number | null => scaled(raw, 1000, LAND_MIN, LAND_MAX);
  export const coastFromAddress = (raw: string | null): number | null => scaled(raw, 100, COAST_MIN, COAST_MAX);

  const flag = (raw: string | null): boolean | null => (raw === null ? null : raw === "1");

  export function readWorldKeys(p: URLSearchParams): WorldKeys {
    return {
      seed: seedFromHash(p.get("seed")),
      style: oneOf(p.get("style"), STYLE_NAMES),
      type: oneOf(p.get("type"), MAP_TYPES),
      band: oneOf(p.get("band"), CLIMATE_BANDS),
      land: landFromAddress(p.get("land")),
      coast: coastFromAddress(p.get("coast")),
    };
  }

  export function readDressKeys(p: URLSearchParams): DressKeys {
    return {
      theme: oneOf(p.get("theme"), THEME_NAMES),
      legend: flag(p.get("legend")),
      arms: flag(p.get("arms")),
      beasts: flag(p.get("beasts")),
    };
  }

  export function parsePrintRoomAddress(hash: string): PrintRoomAddress {
    const p = new URLSearchParams(hash.startsWith("#") ? hash.slice(1) : hash);
    const allowed = <T extends string>(key: string, list: readonly string[]): T | null => {

    };

  const ROOT = process.argv[2];

  const files: string[] = [];
  const walk = (d: string): void => {
    for (const n of readdirSync(d)) {
      const p = join(d, n);
      if (statSync(p).isDirectory()) walk(p);
      else if (p.endsWith(".ts")) files.push(p);
    }

  const edges = new Map<string, string[]>();
  const re = /^\s*(import|export)\s+(?!type\b)([^;]*?)\s+from\s+["'](\.[^"']+)["']/gms;
  for (const f of files) {
    const text = readFileSync(f, "utf8");
    const out: string[] = [];

      if (/^\{\s*type\s[^,}]*\}$/.test(m[2]!.trim())) continue;
      out.push(resolve(dirname(f), m[3]!));
    }
    edges.set(f, out);

  const cycles = new Set<string>();
  const stack: string[] = [];
  const onStack = new Set<string>();
  const done = new Set<string>();
  const dfs = (f: string): void => {
    stack.push(f);
    onStack.add(f);
    for (const t of edges.get(f) ?? []) {
      if (onStack.has(t)) {
        const cyc = stack.slice(stack.indexOf(t)).map((x) => relative(ROOT, x));
        const key = [...cyc].sort().join(" | ");
        if (!cycles.has(key)) {
          cycles.add(key);
          console.log("cycle: " + [...cyc, relative(ROOT, t)].join(" -> "));
        }
      } else if (!done.has(t) && edges.has(t)) dfs(t);
    }
    stack.pop();
    onStack.delete(f);
    done.add(f);
  };
  for (const f of files) if (!done.has(f)) dfs(f);
  console.log(`${files.length} files, ${cycles.size} cycles`);
