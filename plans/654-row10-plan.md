## The ruling this row builds to

- Item 4: writes into handed-in objects: **page elements only are accepted**; the other kinds are fixed, and the engine fills return new values under a byte-for-byte proof.
- Item 5: the accepted writes are excused by **one settings line** (`ignorePropertyModificationsFor`) listing parameter names, **after the element parameters are renamed to names used for nothing else**, so `f` is not excused.
- Item 7: up to three cold `vellum-pr-skeptic` rounds; a finding not fixed is filed or becomes an `errata/` row in the same diff.

**What "fixed" means here** (skeptic 6): no write goes through an object a caller handed the function in; a record the enclosing controller or test itself owns may be written, and an engine function returns a new value instead of filling one it was handed. By that criterion the table-drag carry, the five engine fills and the three test setups become writes into nothing handed in, and the voyage session becomes a record its own controller writes in place (the session is still mutated, by its owner).

### The 7 `deps` element writes: OPEN, Alex's (decision A)

Three functions write into page elements their `deps` record carries beside callbacks and settings: `bindChartDrawer` (`ChartDrawerDeps`: seven elements, five callbacks, a string), `makeAnnouncer` (`AnnounceDeps`: the pill, which is the structural `AnnouncePill` rather than an element type, two timer callbacks, two numbers) and `bindTableLeaf` (`TableLeafDeps`: eight elements, a media query whose `matches` is NOT readonly, a callback). Every top-level field of the three is `readonly`; the reachable writes are into the elements and, in `TableLeafDeps`, into `narrow.matches` (skeptic 8). The candidate treatments:

- **A1, take the elements out into local names** at the top of each function (`const { count, road, tab, full } = deps;`, and `pill`, `tableTab`), the idiom `createVoyage` and `createPlaceOverlay` open with today. **This is aliasing**: the same seven writes still happen, through local names the rule does not watch, and the same move would hide a state-record write just as well; it is honest only because what it moves is a page-element write, the kind ruling 4 accepts (skeptic 6). `deps` stays a watched parameter; 13 excused names; 3 files, one line each. CT8 and CT10 read lines A1 does not touch.
- **A2, split each record**: the elements travel in their own `readonly` record under an excused name (`drawerEls`, `leafEls`, and `pillEl` for the announcer's one element), the callbacks and settings stay in `deps`. The one form consistent with ruling 5's single mechanism. Changes the three signatures and every caller and test that builds them or reads them as text (skeptic 1): `src/site/explorer/app.ts` (three calls), `src/site/portfolio/app.ts`, `test/site/announce.test.ts` (including its source-text match on `makeAnnouncer({ pill: ...`), `test/site/chart-drawer-ceremony.test.ts`, `test/site/chart-drawer.test.ts` (CT8, CT10); about 9 files beyond A1's, 16 excused names. `src/site/explorer/chart-drawer.ts` is 386 of 400 lines today and the split interface adds about 3.
- **A3, rename each `deps` to an excused name as it stands.** 16 names and the smallest diff, but it excuses writes through records that also carry callbacks, numbers and a mutable `narrow.matches`, so test 3 would have to admit records with non-element members, which weakens it for every name.
